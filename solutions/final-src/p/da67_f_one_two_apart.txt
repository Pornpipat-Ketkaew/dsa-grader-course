## 1. What the problem says
Fill an array a of length n (1 ≤ n ≤ 1,000,000) with values 0, 1 or 2 so that **a 1 and a 2 are never 1 or 2 positions apart**: if a[i] = 1, then a[i−2], a[i−1], a[i+1], a[i+2] are not 2. Print the number of valid arrays **mod 100,000,007**.

Samples: n = 1 → **3**; n = 3 → **15**; n = 15 → **198799**; n = 214 → **89208675**; n = 545782 → **8393098**. For n = 2 the PDF lists 7 arrays: 00 01 02 10 11 20 22.

## 2. What it really means
Building the array left to right, a new value z only conflicts with the **two previous** values x, y. So the number of ways to continue depends only on those two cells: they are the DP state.

```text
... x y | z       z may be appended if no pair among (x, z), (y, z) is {1, 2}
                  (the pair (x, y) was already checked when y was added)

f[x][y] = number of valid arrays of the current length ending with x, y
next:     g[y][z] += f[x][y]   for every x, y, z with (x,y,z) valid

9 states (x, y), at most 27 moves per step, n steps
```

:::hint Hint 1
When you write the array from left to right, which earlier cells can a new cell possibly conflict with? Make those cells the state.
:::
:::hint Hint 2
Let f[x][y] count valid prefixes ending in x, y. For each next value z, add f[x][y] into g[y][z] when none of the pairs (x,y), (y,z), (x,z) is a 1 next to a 2. Start at length 2, repeat to length n, sum the 9 entries, take mod after every addition.
:::

## 3. What, why, how
- **What:** a counting DP over positions with state (second-to-last value, last value).
- **Why two cells are enough:** the rule only looks at distances 1 and 2. When z is placed at position i, the cells it must be checked against are i−1 and i−2, which are y and x. Anything earlier is at distance ≥ 3 and cannot conflict.
- **How:**
  - `ok3(x, y, z)`: true if none of (x,y), (y,z), (x,z) is {1,2}.
  - n = 1 is a special case: 3.
  - Length 2: f[x][y] = 1 if (x, y) is not {1,2}. (Using `ok3(0, x, y)` checks just that, since 0 conflicts with nothing.)
  - For len = 3..n: g = 0; for all x, y, z with ok3: g[y][z] += f[x][y] (mod); f = g.
  - Answer: the sum of f (mod).
- **Cost:** 27 · n ≈ 2.7 × 10⁷ tiny steps for n = 10⁶; memory O(1).

## 5. Traps
- **The modulus is 100,000,007**, not the usual 1,000,000,007. Copying the habit fails every big sample.
- **State = only the last cell:** misses "1 _ 2" with a gap of one, which is also forbidden. Sample n = 3 would give 17 instead of 15 (1 0 2 and 2 0 1 sneak in).
- **n = 1** must print 3; a loop that starts at length 2 and sums would print 7.
- **Overflow:** keep every entry below the modulus; the sum of 3 entries of 10⁸ fits in `long long` easily.
- **Storing all n rows:** 10⁶ × 9 numbers is fine (72 MB with `long long`), but two rows are enough.

## 6. Background
Lesson 15. "Strings that avoid a pattern within distance d" are counted with a DP whose state is the last d symbols, which is a walk on a small automaton. The step is a fixed 9 × 9 matrix, so the count for n up to 10¹⁸ could be found with matrix fast power in O(9³ log n), the trick from [Matrix modulo](#a60_q1_matmod) and [Linear recurrence](#da66_f1_linear_recurrence).

## 3. อะไร ทำไม อย่างไร
- **อะไร:** DP นับจำนวนไล่ตามตำแหน่ง state คือ (ค่ารองสุดท้าย, ค่าสุดท้าย)
- **ทำไมสองช่องพอ:** กฎดูแค่ระยะ 1 และ 2 เมื่อวาง z ที่ตำแหน่ง i ช่องที่ต้องเช็กคือ i−1 และ i−2 ซึ่งก็คือ y และ x ช่องที่ก่อนหน้านั้นห่าง ≥ 3 จึงขัดกันไม่ได้
- **อย่างไร:**
  - `ok3(x, y, z)`: จริงเมื่อไม่มีคู่ไหนใน (x,y), (y,z), (x,z) เป็น {1,2}
  - n = 1 เป็นกรณีพิเศษ: 3
  - ความยาว 2: f[x][y] = 1 ถ้า (x, y) ไม่ใช่ {1,2} (ใช้ `ok3(0, x, y)` เช็กแค่นั้นพอดี เพราะ 0 ไม่ขัดกับอะไร)
  - สำหรับ len = 3..n: g = 0; สำหรับทุก x, y, z ที่ ok3: g[y][z] += f[x][y] (mod) แล้ว f = g
  - คำตอบ: ผลรวมของ f (mod)
- **ต้นทุน:** 27 · n ≈ 2.7 × 10⁷ ขั้นเล็ก ๆ เมื่อ n = 10⁶ หน่วยความจำ O(1)

## 5. จุดที่มักพลาด
- **ตัว mod คือ 100,000,007** ไม่ใช่ 1,000,000,007 ที่คุ้นเคย ลอกตามความเคยชินจะผิดทุกตัวอย่างที่ใหญ่
- **state = แค่ช่องสุดท้าย:** พลาดรูปแบบ "1 _ 2" ที่เว้นหนึ่งช่องซึ่งก็ห้ามเหมือนกัน n = 3 จะได้ 17 แทน 15 (1 0 2 และ 2 0 1 หลุดเข้ามา)
- **n = 1** ต้องพิมพ์ 3 ลูปที่เริ่มที่ความยาว 2 แล้วรวมจะพิมพ์ 7
- **ล้น:** เก็บทุกช่องให้น้อยกว่าตัว mod ผลรวม 3 ค่าขนาด 10⁸ ใส่ `long long` ได้สบาย
- **เก็บทั้ง n แถว:** 10⁶ × 9 ตัวก็ไหว (72 MB ถ้าใช้ `long long`) แต่สองแถวก็พอ
