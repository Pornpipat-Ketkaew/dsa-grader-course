## 1. What the problem says
Fill a table of **2 rows and n columns** with 0s and 1s so that **no two 1s are in adjacent cells** (sharing a side: left/right or up/down). Count the possible tables, mod 100,000,007. n ≤ 10,000,000.

The PDF lists the 7 tables for n = 2 and the 17 for n = 3, and forbids hard-coding answers (its example of forbidden code reveals 41 for n = 4 and 99 for n = 5). Samples: n = 10 → 8119, n = 15 → 665857, n = 5467 → 8124108.

## 2. What it really means
Look at one column: it cannot be `1/1` (vertical neighbours). So every column is one of **three** shapes:

```text
 e      t      b
 0      1      0
 0      0      1
```

And two neighbouring columns may not put a 1 in the same row: t cannot follow t, b cannot follow b. Everything else is allowed.

```text
            next:  e    t    b
 previous e:       ✓    ✓    ✓
 previous t:       ✓    ✗    ✓
 previous b:       ✓    ✓    ✗
```

:::hint Hint 1
To decide whether a new column is allowed, you only need to know the **previous column**, not the whole table. That is the state.
:::
:::hint Hint 2
Keep three counters: tables of the current length ending in e, in t, in b. Update all three when you add a column.
:::

## 3. What, why, how
- **What:** a DP whose state is (length, shape of the last column). Only 3 shapes, so the state per length is 3 numbers.
- **Recurrence** (read the table above by columns):
  - e' = e + t + b (an empty column can follow anything);
  - t' = e + b;
  - b' = e + t.
- **Start:** length 1 → e = t = b = 1 (3 tables). Answer: e + t + b at length n.
- **Why it is correct:** every valid table of length i+1 is a valid table of length i plus one column that is compatible with its last column, and each such pair is counted exactly once.
- **Memory:** n = 10⁷ would need 3 arrays of 10⁷ entries if we kept the whole table. We only need the previous column's three numbers: O(1) memory.
- **Overflow:** each counter is < 100,000,007, so a sum of three is < 3.1·10⁸ and fits even in `int`; `long long` is used for safety.

## 5. Traps
- **Forgetting vertical adjacency:** if `1/1` were allowed there would be 4 shapes and the answer for n = 2 would be wrong.
- **An array of size 10⁷ per state:** 3 · 10⁷ `long long` = 240 MB; unnecessary.
- **Mod 1,000,000,007 by habit:** this problem uses **100,000,007** (one fewer zero).
- **Hard-coding a table of answers:** explicitly forbidden.

## 1. โจทย์บอกอะไร
เติมตาราง **2 แถว n คอลัมน์** ด้วย 0 และ 1 โดย **ไม่มีเลข 1 สองตัวอยู่ในช่องที่ติดกัน** (มีด้านร่วมกัน: ซ้าย/ขวา หรือ บน/ล่าง) นับจำนวนตารางที่เป็นไปได้ mod 100,000,007 โดย n ≤ 10,000,000

PDF แสดงตาราง 7 แบบเมื่อ n = 2 และ 17 แบบเมื่อ n = 3 และห้ามเขียนคำตอบตายตัว (ตัวอย่างโค้ดต้องห้ามของมันเผยว่า n = 4 ได้ 41 และ n = 5 ได้ 99) ตัวอย่าง: n = 10 → 8119, n = 15 → 665857, n = 5467 → 8124108

## 2. จริง ๆ แล้วถามอะไร
ดูคอลัมน์เดียว: เป็น `1/1` ไม่ได้ (บนล่างติดกัน) แต่ละคอลัมน์จึงเป็นได้แค่ **สาม** แบบ:

```text
 e      t      b
 0      1      0
 0      0      1
```

และคอลัมน์ที่ติดกันจะมีเลข 1 ในแถวเดียวกันไม่ได้: t ตามหลัง t ไม่ได้ b ตามหลัง b ไม่ได้ นอกนั้นได้หมด

```text
            next:  e    t    b
 previous e:       ✓    ✓    ✓
 previous t:       ✓    ✗    ✓
 previous b:       ✓    ✓    ✗
```

:::hint คำใบ้ 1
จะรู้ว่าคอลัมน์ใหม่ใช้ได้ไหม ต้องรู้แค่ **คอลัมน์ก่อนหน้า** ไม่ต้องรู้ทั้งตาราง นั่นคือสถานะ
:::
:::hint คำใบ้ 2
เก็บตัวนับสามตัว: จำนวนตารางความยาวปัจจุบันที่ลงท้ายด้วย e, t, b แล้วอัปเดตทั้งสามเมื่อเพิ่มคอลัมน์
:::

## 3. อะไร ทำไม อย่างไร
- **อะไร:** DP ที่สถานะคือ (ความยาว, รูปแบบของคอลัมน์สุดท้าย) มีแค่ 3 รูปแบบ สถานะต่อความยาวจึงเป็นตัวเลข 3 ตัว
- **ความสัมพันธ์** (อ่านตารางข้างบนตามคอลัมน์):
  - e' = e + t + b (คอลัมน์ว่างตามหลังอะไรก็ได้)
  - t' = e + b
  - b' = e + t
- **เริ่มต้น:** ความยาว 1 → e = t = b = 1 (3 ตาราง) คำตอบคือ e + t + b ที่ความยาว n
- **ทำไมถูก:** ทุกตารางที่ถูกต้องความยาว i+1 คือตารางที่ถูกต้องความยาว i บวกคอลัมน์หนึ่งที่เข้ากันได้กับคอลัมน์สุดท้าย และแต่ละคู่ถูกนับครั้งเดียวพอดี
- **หน่วยความจำ:** ถ้าเก็บทั้งตาราง n = 10⁷ ต้องใช้ 3 อาร์เรย์ขนาด 10⁷ แต่เราต้องการแค่ตัวเลขสามตัวของคอลัมน์ก่อนหน้า: O(1)
- **การล้น:** แต่ละตัวนับ < 100,000,007 ผลบวกสามตัว < 3.1·10⁸ ใส่ `int` ได้ด้วยซ้ำ ใช้ `long long` เผื่อไว้
