==== en
## 1. What the problem says
A monthly comic author often skips months. You know the n (year, month) pairs when an issue was published (not sorted). For each of m questions (year, month):

- if an issue was published **that month** → print `0 0`;
- if the month is **before the first issue** → print `-1 -1`;
- otherwise print the year and month of the **latest issue before** it.

All 2·m numbers go on **one line**, separated by spaces. 2 ≤ n, m ≤ 200,000; year 1..1,000,000.

## 2. What it really means
"Find the predecessor of a value in a set" — a classic binary-search job once the months are on one number line.

```text
published: 2019-10, 2020-01, 2020-08
timeline:  ... 2019-10 ──── 2020-01 ──────── 2020-08 ────►
ask 2019-12:          ▲ latest before = 2019-10
ask 2020-11:                                     ▲ latest before = 2020-08
ask 2018-01: ▲ nothing before → -1 -1
```

## 3. What, why, how
- **Encode** (year, month) as `key = year·12 + (month − 1)`. Then comparing keys = comparing dates, and Dec of year y (y·12+11) is right before Jan of y+1. Decode with `key / 12` and `key % 12 + 1`.
- **Sort** the n keys (the input isn't sorted).
- For each question: `idx = lower_bound(key)` = first issue **≥ key**.
  - `pub[idx] == key` → `0 0`.
  - `idx == 0` → no issue before → `-1 -1`.
  - else → `pub[idx − 1]` is the last issue **< key**.
- O((n + m) log n).

## 5. Traps
- **No space between answers:** printing `0 0` then `2019 10` with no separator glues the numbers (`0 02019 10`). Put a space between answers.
- **Encoding `year·100 + month`** also sorts correctly, but then "the month before January" isn't key − 1 — only use it for comparisons.
- **Forgetting to sort** (sample 2 is unsorted).
- **`upper_bound` by mistake**: `upper_bound(key) − 1` is the last ≤ key, which mixes the "equal" case into the predecessor case. Check equality first with lower_bound.

## 6. Background
Lesson 08: **predecessor query = `lower_bound(x) − 1`** (last element < x). Turning a multi-part key (year, month) into one integer that preserves order is a handy trick (minutes since midnight, row·W + col, …). `std::set::lower_bound` does the same if updates are mixed with queries.

## 1. โจทย์บอกอะไร
นักเขียนการ์ตูนรายเดือนชอบหยุดพัก เรารู้ (ปี, เดือน) ที่มีการตีพิมพ์ n ตอน (ไม่เรียง) สำหรับคำถาม m ข้อ (ปี, เดือน):

- ถ้าเดือนนั้น **มีการตีพิมพ์** → พิมพ์ `0 0`
- ถ้าเดือนนั้นอยู่ **ก่อนตอนแรก** → พิมพ์ `-1 -1`
- ไม่อย่างนั้นพิมพ์ปีและเดือนของ **ตอนล่าสุดก่อนหน้า**

ตัวเลขทั้ง 2·m ตัวอยู่ใน **บรรทัดเดียว** คั่นด้วยช่องว่าง 2 ≤ n, m ≤ 200,000 ปี 1..1,000,000

## 2. จริง ๆ แล้วถามอะไร
"หาตัวก่อนหน้า (predecessor) ของค่าหนึ่งในเซต" — งานถนัดของ binary search เมื่อวางเดือนทั้งหมดไว้บนเส้นจำนวนเส้นเดียว

```text
published: 2019-10, 2020-01, 2020-08
timeline:  ... 2019-10 ──── 2020-01 ──────── 2020-08 ────►
ask 2019-12:          ▲ latest before = 2019-10
ask 2020-11:                                     ▲ latest before = 2020-08
ask 2018-01: ▲ nothing before → -1 -1
```

## 3. อะไร ทำไม อย่างไร
- **แปลง** (ปี, เดือน) เป็น `key = ปี·12 + (เดือน − 1)` แล้วการเทียบ key = การเทียบวันที่ และธันวาคมของปี y (y·12+11) อยู่ติดกับมกราคมของปี y+1 พอดี แปลงกลับด้วย `key / 12` และ `key % 12 + 1`
- **sort** key ทั้ง n ตัว (ข้อมูลไม่ได้เรียงมา)
- แต่ละคำถาม: `idx = lower_bound(key)` = ตอนแรกที่ **≥ key**
  - `pub[idx] == key` → `0 0`
  - `idx == 0` → ไม่มีตอนก่อนหน้า → `-1 -1`
  - ไม่อย่างนั้น → `pub[idx − 1]` คือตอนสุดท้ายที่ **< key**
- เวลา O((n + m) log n)

```text
pub (sorted): [24237][24240][24247]
                 0      1      2
ถาม 24239: lower_bound → idx = 1 (ค่า 24240 ≠ 24239)
           ตัวก่อนหน้า = pub[0] = 24237 → 2019 เดือน 10
```

## 5. จุดที่มักพลาด
- **ไม่มีช่องว่างระหว่างคำตอบ:** พิมพ์ `0 0` ต่อด้วย `2019 10` โดยไม่คั่น ตัวเลขจะติดกัน (`0 02019 10`) ต้องใส่ช่องว่างระหว่างคำตอบ
- **แปลงเป็น `ปี·100 + เดือน`** ก็เรียงถูก แต่ "เดือนก่อนมกราคม" จะไม่ใช่ key − 1 ใช้ได้แค่เปรียบเทียบ
- **ลืม sort** (ตัวอย่างที่ 2 ไม่เรียง)
- **ใช้ `upper_bound` ผิดที่:** `upper_bound(key) − 1` คือตัวสุดท้ายที่ ≤ key ทำให้กรณี "เท่ากัน" ปนกับกรณีตัวก่อนหน้า ให้เช็กเท่ากันก่อนด้วย lower_bound

## 6. ความรู้พื้นฐาน
บทที่ 08: **หาตัวก่อนหน้า = `lower_bound(x) − 1`** (ตัวสุดท้ายที่ < x) การแปลง key หลายส่วน (ปี, เดือน) เป็นจำนวนเต็มตัวเดียวที่ยังเรียงถูกเป็นเทคนิคที่ใช้บ่อย (นาทีนับจากเที่ยงคืน, แถว·W + คอลัมน์, …) ถ้ามีการเพิ่มข้อมูลสลับกับคำถาม ใช้ `std::set::lower_bound` ได้แบบเดียวกัน
