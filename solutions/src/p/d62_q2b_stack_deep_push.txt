==== en
## 1. What the problem says
Add `void deep_push(size_t pos, T value)` to CP::stack: push value so that it ends up **pos places below the top**. `deep_push(0, v)` is a normal push; on {10,20,30} (top on the right) `deep_push(3, v)` gives {v,10,20,30}. pos ≤ size().

- `main` commands: `u x` push, `o` pop, `d pos v` deep_push, `p` print bottom → top, `q` quit.

## 2. What it really means
CP::stack stores bottom → top in `mData[0 .. mSize−1]`; the **top is the last slot**. "pos below the top" is array index **idx = mSize − pos**.

```text
mData:  [ 1 | 2 | 3 | 4 ]        mSize = 4
index:    0   1   2   3 ← top
pos:      4   3   2   1   0 (= above the top)
d 0 10 → idx 4 → [1 2 3 4 10]
d 5 11 → idx 0 → [11 1 2 3 4 10]
```

## 3. What, why, how
- It's "insert at index idx" in a vector: make room for one, shift `mData[idx .. n−1]` right by 1 (**right to left**), write the value, `mSize++`.
- `ensureCapacity(mSize + 1)` may reallocate — we use indices, not pointers, so that's safe.
- Cost O(pos): only the pos elements above idx move.

## 5. Traps
- **Counting from the bottom:** idx = pos is wrong; pos is measured from the **top**.
- **idx = mSize − pos − 1** puts the value one slot too low (deep_push(0) would land under the top instead of on it).
- **Shifting left to right** duplicates one element and loses the rest.
- **Forgetting `ensureCapacity`** writes past the array when it is full.

## 6. Background
Lesson 04: a CP::stack is a vector where only the end is used. Any "k-th from the top" is `mData[mSize − 1 − k]`. Deep push = vector insert at `mSize − pos` (see Multiple Add for the shift pattern, Mitosis for a harder version).

## 1. โจทย์บอกอะไร
เพิ่ม `void deep_push(size_t pos, T value)` ให้ CP::stack: push value ให้ไปอยู่ **ลึกลงไปจาก top pos ช่อง** `deep_push(0, v)` คือ push ปกติ; ถ้า stack เป็น {10,20,30} (top อยู่ขวา) `deep_push(3, v)` จะได้ {v,10,20,30} รับประกันว่า pos ≤ size()

- คำสั่งใน `main`: `u x` push, `o` pop, `d pos v` deep_push, `p` พิมพ์จาก bottom → top, `q` จบ

## 2. จริง ๆ แล้วถามอะไร
CP::stack เก็บข้อมูลจาก bottom → top ใน `mData[0 .. mSize−1]` **top คือช่องสุดท้าย** ดังนั้น "ลึกจาก top pos ช่อง" คือ index **idx = mSize − pos**

```text
mData:  [ 1 | 2 | 3 | 4 ]        mSize = 4
index:    0   1   2   3 ← top
pos:      4   3   2   1   0 (= above the top)
d 0 10 → idx 4 → [1 2 3 4 10]
d 5 11 → idx 0 → [11 1 2 3 4 10]
```

นึกภาพกองจาน: deep_push(2, v) คือยกจาน 2 ใบบนสุดขึ้น วางจาน v ลงไป แล้ววางสองใบกลับ

## 3. อะไร ทำไม อย่างไร
- นี่คือ "แทรกที่ index idx" ของ vector: เพิ่มที่หนึ่งช่อง, เลื่อน `mData[idx .. n−1]` ไปขวา 1 ช่อง (**จากขวาไปซ้าย**), เขียนค่า, `mSize++`
- `ensureCapacity(mSize + 1)` อาจจองที่ใหม่ แต่เราใช้ index ไม่ใช่พอยน์เตอร์ จึงปลอดภัย
- เวลา O(pos): ขยับแค่ pos ตัวที่อยู่เหนือ idx

## 5. จุดที่มักพลาด
- **นับจาก bottom:** idx = pos ผิด pos นับจาก **top**
- **idx = mSize − pos − 1** ทำให้ค่าต่ำไปหนึ่งช่อง (deep_push(0) จะไปอยู่ใต้ top แทนที่จะอยู่บน top)
- **เลื่อนจากซ้ายไปขวา** ทำให้ข้อมูลตัวหนึ่งซ้ำและที่เหลือหาย
- **ลืม `ensureCapacity`** จะเขียนเลยอาร์เรย์ตอนเต็ม
