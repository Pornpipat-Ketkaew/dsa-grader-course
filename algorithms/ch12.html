Divide & conquerแบ่งแยกและเอาชนะ (Divide & Conquer)

Split into halves, solve each half the same way, combine.

แบ่งเป็นครึ่ง แก้แต่ละครึ่งด้วยวิธีเดิม แล้วรวมผล

1Toolkit for this chapter

The pattern

  1. Divide the input into parts of the same shape (halves, quarters).
  2. Conquer each part with the same function (recursion).
  3. Combine the parts' answers.

The recursion depth is log n, and the running time follows from "how many sub-calls, how big, how costly is the combine":

recurrence time example
T(n) = T(n/2) + O(1) O(log n) fast power (Matrix Modulo)
T(n) = 2T(n/2) + O(n) O(n log n) merge sort (Remaining Merge)
T(n) = 4T(n/4)… on a grid O(output) Recur Matrix
T(n) = 2T(n/2) + O(1) with extra info returned O(n) Virus 2

Tips

  • Pass offsets (top, left, start, length) instead of copying sub-arrays.
  • Let the function return more than the yes/no you need when the parent needs it (a count, a sum): it avoids re-scanning (Virus 2 returns the number of 1s).
  • Fast power: xⁿ = (x^{n/2})² · (x if n is odd); works for matrices and under a modulus.

1ชุดเครื่องมือของบทนี้

รูปแบบ

  1. แบ่ง ข้อมูลเป็นส่วนที่รูปร่างเหมือนกัน (ครึ่ง, สี่ส่วน)
  2. เอาชนะ แต่ละส่วนด้วยฟังก์ชันเดิม (recursion)
  3. รวม คำตอบของแต่ละส่วน

ความลึกของ recursion คือ log n และเวลาที่ใช้มาจาก "เรียกย่อยกี่ครั้ง ขนาดเท่าไร การรวมแพงแค่ไหน":

ความสัมพันธ์เวียนเกิด เวลา ตัวอย่าง
T(n) = T(n/2) + O(1) O(log n) ยกกำลังเร็ว (Matrix Modulo)
T(n) = 2T(n/2) + O(n) O(n log n) merge sort (Remaining Merge)
T(n) = 4T(n/4)… บนตาราง O(ขนาดผลลัพธ์) Recur Matrix
T(n) = 2T(n/2) + O(1) พร้อมคืนข้อมูลเพิ่ม O(n) Virus 2

เคล็ดลับ

  • ส่ง offset (top, left, start, length) แทนการคัดลอกอาร์เรย์ย่อย
  • ให้ฟังก์ชัน คืนค่ามากกว่าใช่/ไม่ใช่ เมื่อตัวแม่ต้องใช้ (จำนวน, ผลรวม): ไม่ต้องไล่ซ้ำ (Virus 2 คืนจำนวนเลข 1)
  • ยกกำลังเร็ว: xⁿ = (x^{n/2})² · (x ถ้า n คี่) ใช้ได้กับเมทริกซ์และภายใต้ mod
