69_AG1

BraceletBracelet (สร้อยข้อมือ)

Backtracking over a multiset (permutations with limited counts)Canonical form: keep a string only if it is ≤ its reverseBacktracking บน multiset (เรียงสับเปลี่ยนแบบจำนวนจำกัด)รูปแบบมาตรฐาน: เก็บสตริงเมื่อมัน ≤ ตัวกลับด้านเท่านั้นO(K · N · (number of arrangements)) time · O(N + output) memory★★☆

Generate every arrangement of N beads in dictionary order with a remaining[] count per letter (the permutation generator with counts). A bracelet and its flip are the same, so print an arrangement only when it is ≤ its reverse: that picks exactly one of each pair, and a palindrome once.

สร้างทุกการเรียงลูกปัด N เม็ดตามลำดับพจนานุกรม โดยมี remaining[] นับจำนวนที่เหลือของแต่ละตัวอักษร (ตัวสร้าง permutation แบบมีจำนวน) สร้อยกับตัวที่พลิกแล้วคือแบบเดียวกัน จึงพิมพ์การเรียงเฉพาะเมื่อมัน ≤ ตัวกลับด้าน ซึ่งเลือกหนึ่งตัวจากแต่ละคู่พอดี และ palindrome ครั้งเดียว

1Technique: backtracking over a multiset, then a canonical form

Permutations with repeated items. When the items are "c₁ copies of A, c₂ copies of B, …", the generator keeps remaining[letter] instead of used[value]. At each position it tries every letter that still has copies, in alphabetical order:

for (bead = 0; bead < kinds; bead++)
    if (remaining[bead] > 0) { remaining[bead]--; bracelet[position] = 'A' + bead;
                               place(position + 1);
                               remaining[bead]++; }

Because letters are tried in order, the arrangements come out in dictionary order, and each distinct arrangement appears exactly once (two copies of A are never told apart).

Canonical form. When several objects count as "the same" (here: a string and its reverse), pick one fixed representative from each group, usually the smallest, and output only representatives.

2How it maps onto this problem

Step 1: generate all arrangements

Here not every bead has to be used: c_i is the most we may use. The generator above already handles that: it just never takes a letter whose count reached 0. The bracelet length is N, so the recursion stops at position N.

Step 2: one representative per bracelet

A bracelet s and its flip reverse(s) are the same bracelet. The statement asks for the one that comes first, so:

print s only when s ≤ reverse(s).

  • If s < reverse(s): s is printed and reverse(s) (also generated, later) is skipped.
  • If s = reverse(s) (a palindrome, like ABA): printed once, because it is generated once.

The comparison walks from both ends inward and stops at the first different pair: the first index where s and reverse(s) differ.

sample 3 (N = 4, two A, two C), all 6 arrangements in dictionary order:
AACC  ≤ CCAA   print
ACAC  ≤ CACA   print
ACCA  = ACCA   print (palindrome)
CAAC  = CAAC   print (palindrome)
CACA  > ACAC   skip
CCAA  > AACC   skip                    → 4

Step 3: reading the counts

Every c_i is at most N ≤ 9, so it is a single digit. Sample 4 writes the 26 counts with no spaces (10000000000010000000000001), so read one digit character at a time. cin >> digit with a char skips spaces too, so the same loop reads both styles.

Step 4: size

The statement guarantees at most 100 000 bracelets, so at most about 200 000 arrangements are generated; each costs O(N) for the check and O(K) per level of the recursion. Build the output in one string and print it once.

Traps
  • Reading the counts with cin >> int: on sample 4 that reads one huge number.
  • Removing duplicates with a set of strings after generating everything: works, but the ≤ reverse test is simpler and already in order.
  • Printing reverse(s) instead of s, or printing palindromes twice.
  • P = 0 still prints the line 0.

3Solution

main.cpp⬇ .cpp
#include <iostream>
#include <string>
using namespace std;

int length, kinds;
int remaining[26];          // remaining[bead] = beads of this letter still unused
string bracelet;            // the beads placed so far (filled left to right)
string output;
int found = 0;

void place(int position) {
    if (position == length) {
        // A flipped copy of this bracelet is also generated somewhere; keep only
        // the copy that comes first, i.e. the one that is <= its reverse.
        // index = 0..length/2-1 (outside in): the first mismatching pair decides
        for (int index = 0; index < length / 2; index++) {
            char left = bracelet[index], right = bracelet[length - 1 - index];
            if (left < right) break;            // smaller than the reverse: keep
            if (left > right) return;           // the reverse comes first: skip
        }
        found++;
        output += bracelet;
        output += '\n';
        return;
    }
    // bead = 'A'.. in increasing order, so bracelets come out in dictionary order
    for (int bead = 0; bead < kinds; bead++) {
        if (remaining[bead] == 0) continue;
        remaining[bead]--;
        bracelet[position] = char('A' + bead);
        place(position + 1);
        remaining[bead]++;                      // un-choose
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> length >> kinds;
    // bead = 0..kinds-1: every count is a single digit (c <= N <= 9), and the
    // digits may be written without spaces, so read them one character at a time
    for (int bead = 0; bead < kinds; bead++) {
        char digit;
        cin >> digit;
        remaining[bead] = digit - '0';
    }
    bracelet.assign(length, ' ');
    place(0);
    cout << found << '\n' << output;
}

1เทคนิค: backtracking บน multiset แล้วเลือกตัวแทน

permutation ที่มีของซ้ำ เมื่อของคือ "A จำนวน c₁ ชิ้น B จำนวน c₂ ชิ้น …" ตัวสร้างจะเก็บ remaining[letter] แทน used[value] ที่แต่ละตำแหน่งลองทุกตัวอักษรที่ยังเหลือ ตามลำดับตัวอักษร:

for (bead = 0; bead < kinds; bead++)
    if (remaining[bead] > 0) { remaining[bead]--; bracelet[position] = 'A' + bead;
                               place(position + 1);
                               remaining[bead]++; }

เพราะลองตัวอักษรตามลำดับ การเรียงจึงออกมาตาม ลำดับพจนานุกรม และแต่ละการเรียงที่ต่างกันปรากฏครั้งเดียวพอดี (A สองเม็ดไม่ถูกแยกว่าเป็นเม็ดไหน)

ตัวแทนมาตรฐาน (canonical form) เมื่อของหลายชิ้นนับเป็น "แบบเดียวกัน" (ในข้อนี้: สตริงกับตัวกลับด้าน) ให้เลือกตัวแทนที่แน่นอนหนึ่งตัวจากแต่ละกลุ่ม ปกติคือตัวที่น้อยที่สุด แล้วพิมพ์เฉพาะตัวแทน

2นำมาใช้กับโจทย์นี้อย่างไร

ขั้นที่ 1: สร้างทุกการเรียง

ในข้อนี้ไม่ต้องใช้ลูกปัดครบทุกเม็ด: c_i คือจำนวน มากที่สุด ที่ใช้ได้ ตัวสร้างข้างบนจัดการให้แล้ว: มันไม่หยิบตัวอักษรที่จำนวนเหลือ 0 ความยาวสร้อยคือ N recursion จึงหยุดที่ตำแหน่ง N

ขั้นที่ 2: ตัวแทนหนึ่งตัวต่อสร้อยหนึ่งแบบ

สร้อย s กับตัวที่พลิก reverse(s) คือสร้อยแบบเดียวกัน โจทย์ต้องการตัวที่มาก่อน ดังนั้น:

พิมพ์ s เฉพาะเมื่อ s ≤ reverse(s)

  • ถ้า s < reverse(s): พิมพ์ s และ reverse(s) (ซึ่งถูกสร้างทีหลังเช่นกัน) ถูกข้าม
  • ถ้า s = reverse(s) (palindrome เช่น ABA): พิมพ์ครั้งเดียว เพราะถูกสร้างครั้งเดียว

การเทียบเดินจากสองปลายเข้าหากลาง และหยุดที่คู่แรกที่ต่างกัน: ดัชนีแรกที่ s กับ reverse(s) ต่างกัน

ตัวอย่าง 3 (N = 4, A สองเม็ด, C สองเม็ด) ทั้ง 6 การเรียงตามลำดับพจนานุกรม:
AACC  ≤ CCAA   พิมพ์
ACAC  ≤ CACA   พิมพ์
ACCA  = ACCA   พิมพ์ (palindrome)
CAAC  = CAAC   พิมพ์ (palindrome)
CACA  > ACAC   ข้าม
CCAA  > AACC   ข้าม                    → 4

ขั้นที่ 3: การอ่านจำนวน

c_i ทุกตัวไม่เกิน N ≤ 9 จึงเป็นเลขหลักเดียว ตัวอย่าง 4 เขียนจำนวนทั้ง 26 ตัวติดกันไม่มีช่องว่าง (10000000000010000000000001) จึงต้องอ่าน ทีละตัวอักษร cin >> digit ที่เป็น char ข้ามช่องว่างให้ด้วย ลูปเดียวจึงอ่านได้ทั้งสองแบบ

ขั้นที่ 4: ขนาด

โจทย์รับประกันว่ามีสร้อยไม่เกิน 100 000 แบบ จึงสร้างการเรียงไม่เกินราว 200 000 แบบ แต่ละแบบใช้ O(N) ในการตรวจ และ O(K) ต่อชั้นของ recursion สร้างผลลัพธ์ใน string เดียวแล้วพิมพ์ครั้งเดียว

กับดัก
  • อ่านจำนวนด้วย cin >> int: ตัวอย่าง 4 จะอ่านได้เลขก้อนใหญ่ก้อนเดียว
  • ลบตัวซ้ำด้วย set ของสตริงหลังสร้างครบ: ใช้ได้ แต่การตรวจ ≤ ตัวกลับด้านง่ายกว่าและเรียงลำดับอยู่แล้ว
  • พิมพ์ reverse(s) แทน s หรือพิมพ์ palindrome สองครั้ง
  • P = 0 ยังต้องพิมพ์บรรทัด 0
