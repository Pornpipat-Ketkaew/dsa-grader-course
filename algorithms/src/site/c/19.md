## How to read this mock exam

Each problem is one technique from an earlier chapter with one twist. In an exam, the fastest route is to name the technique first, then handle the twist:

| problem | technique (chapter) | the twist |
|---|---|---|
| Coloring Book | components by flood fill (16) | each wall is stored in only one of its two cells |
| Bracelet | backtracking over a multiset (11) | keep a string only if it is ≤ its reverse |
| Eternal Merit | DP with states (15) | a second shape (a board with a missing corner) |
| Zipline | Kruskal (18) | maximum tree, 3-D lengths |
| Portal 3 | Dijkstra (17) | state = (room, shots used): a layered graph |

### A checklist that catches most mistakes

- Sizes: does any value or answer exceed 2³¹? Then `long long`.
- Input format: unsorted lists, 1-based labels, digits written without spaces.
- Edge cases: n = 1, empty answers ("print 0"), odd sizes.
- Before coding a greedy or a shortcut, try a small counterexample.

## วิธีอ่านข้อสอบเสมือนจริงชุดนี้

แต่ละข้อคือเทคนิคหนึ่งจากบทก่อน ๆ ที่บิดหนึ่งจุด ในห้องสอบ ทางที่เร็วที่สุดคือบอกชื่อเทคนิคให้ได้ก่อน แล้วค่อยจัดการจุดที่บิด:

| โจทย์ | เทคนิค (บท) | จุดที่บิด |
|---|---|---|
| Coloring Book | component ด้วย flood fill (16) | ขอบแต่ละเส้นเก็บไว้ในช่องเดียวจากสองช่อง |
| Bracelet | backtracking บน multiset (11) | เก็บสตริงเฉพาะเมื่อ ≤ ตัวกลับด้าน |
| Eternal Merit | DP มีสถานะ (15) | รูปทรงที่สอง (กระดานที่ขาดมุม) |
| Zipline | Kruskal (18) | ต้นไม้ที่มากที่สุด ความยาวสามมิติ |
| Portal 3 | Dijkstra (17) | สถานะ = (ห้อง, จำนวนครั้งที่ยิง): กราฟหลายชั้น |

### รายการตรวจที่จับความผิดพลาดส่วนใหญ่ได้

- ขนาด: มีค่าหรือคำตอบไหนเกิน 2³¹ ไหม? ถ้ามีใช้ `long long`
- รูปแบบข้อมูล: รายการที่ไม่เรียง ป้ายเริ่มจาก 1 ตัวเลขที่เขียนติดกันไม่มีช่องว่าง
- กรณีขอบ: n = 1 คำตอบว่าง ("พิมพ์ 0") ขนาดคี่
- ก่อนเขียน greedy หรือทางลัด ลองหาตัวอย่างค้านเล็ก ๆ
