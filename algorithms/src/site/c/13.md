## Toolkit for this chapter

### The greedy recipe

1. Find a **key** to sort by.
2. Walk in that order and **commit** to the locally best choice, never undoing it.
3. **Prove** it with an exchange argument: take any optimal solution that differs from the greedy one at the first point; swap in the greedy choice and show the solution does not get worse. Repeating the swap turns the optimal solution into the greedy one.

### Classic keys

| problem shape | key | why |
|---|---|---|
| most non-overlapping intervals | earliest **finish** | leaves the most room for the rest |
| cover points with fixed-length intervals | leftmost uncovered point, interval pushed right | covers as much to the right as possible |
| fractional knapsack | value per weight, highest first | each unit of capacity earns the most |
| independent choices per item | best (or best and second best) per item | nothing interacts |

### Test before you trust

Greedy rules that "feel right" are often wrong (start earliest, shortest first, …). Before coding, try to break the rule with a 3-item counterexample; the midterm version of Class Selection is built around this.

## ชุดเครื่องมือของบทนี้

### สูตรของ greedy

1. หา **คีย์** ที่ใช้เรียง
2. เดินตามลำดับนั้น และ **ตัดสินใจ** เลือกสิ่งที่ดีที่สุดตอนนี้ โดยไม่ย้อนกลับ
3. **พิสูจน์** ด้วยเหตุผลแลกเปลี่ยน: เอาคำตอบที่ดีที่สุดใด ๆ ที่ต่างจาก greedy ตั้งแต่จุดแรก สลับเอาตัวเลือกของ greedy เข้าไป แล้วแสดงว่าคำตอบไม่แย่ลง ทำซ้ำจนคำตอบที่ดีที่สุดกลายเป็นคำตอบของ greedy

### คีย์คลาสสิก

| รูปแบบโจทย์ | คีย์ | เหตุผล |
|---|---|---|
| ช่วงที่ไม่ทับกันมากที่สุด | **จบ** เร็วที่สุด | เหลือที่ให้ช่วงอื่นมากที่สุด |
| ครอบจุดด้วยช่วงความยาวคงที่ | จุดซ้ายสุดที่ยังไม่ถูกครอบ แล้วดันช่วงไปทางขวา | ครอบไปทางขวาได้มากที่สุด |
| fractional knapsack | มูลค่าต่อน้ำหนัก มากไปน้อย | ความจุแต่ละหน่วยได้มากที่สุด |
| ตัวเลือกที่ไม่ขึ้นต่อกันในแต่ละชิ้น | ดีที่สุด (หรือดีที่สุดและรองลงมา) ต่อชิ้น | ไม่มีอะไรส่งผลต่อกัน |

### ทดสอบก่อนเชื่อ

กฎ greedy ที่ "รู้สึกว่าถูก" มักผิด (เริ่มเร็วที่สุด, สั้นที่สุดก่อน, …) ก่อนเขียนโค้ด ลองหาตัวอย่างค้าน 3 ชิ้น Class Selection ฉบับกลางภาคสร้างขึ้นจากเรื่องนี้
