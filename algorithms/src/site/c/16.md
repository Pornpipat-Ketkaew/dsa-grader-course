## Toolkit for this chapter

### Storing a graph

| structure | edge test | list neighbours | memory | use when |
|---|---|---|---|---|
| adjacency matrix `bool[n][n]` | O(1) | O(n) | O(n²) | n ≤ a few thousand, dense |
| adjacency lists `vector<int>[n]` | O(degree) | O(degree) | O(n + m) | the default for traversal |
| adjacency sets `set<int>[n]` | O(log) | O(degree) | O(n + m) | edges are added and removed |
| implicit (grid) | compute | compute | none | cells with 4 neighbours |

### BFS (queue) and DFS (stack)

```cpp
visited[start] = true; queue.push(start);
while (!queue.empty()) {
    int u = queue.front(); queue.pop();
    for (int v : adj[u]) if (!visited[v]) { visited[v] = true; distance[v] = distance[u] + 1; queue.push(v); }
}
```

- Mark when **pushing**, so nothing enters twice.
- BFS gives **shortest distances in edges** and visits by layers; DFS (the same code with a stack) is enough for reachability and components.
- **Multi-source BFS**: push all sources at distance 0 first; every cell then gets its distance to the nearest source.
- **Depth limit**: stop expanding at distance k (Pandemic, Border Extend, Connection).

### What a traversal can tell you

| question | how |
|---|---|
| number of components | start a traversal from every unvisited vertex, count starts |
| is there a cycle (undirected) | a visited neighbour that is not your BFS parent |
| is a component a path | all degrees ≤ 2 and edges = vertices − 1 |
| the cycle of a unicyclic graph | peel leaves (degree 1) until none remain |
| shortest path between two regions | multi-source BFS from one region until the other is touched |

### BFS (คิว) และ DFS (stack)

```cpp
visited[start] = true; queue.push(start);
while (!queue.empty()) {
    int u = queue.front(); queue.pop();
    for (int v : adj[u]) if (!visited[v]) { visited[v] = true; distance[v] = distance[u] + 1; queue.push(v); }
}
```

- ทำเครื่องหมายตอน **push** ไม่มีอะไรเข้าซ้ำ
- BFS ให้ **ระยะทางสั้นที่สุดเป็นจำนวนเส้น** และไปทีละชั้น DFS (โค้ดเดียวกันแต่ใช้ stack) พอสำหรับการไปถึงและ component
- **BFS หลายจุดเริ่ม**: push ทุกจุดเริ่มที่ระยะ 0 ก่อน ทุกช่องจะได้ระยะถึงจุดเริ่มที่ใกล้ที่สุด
- **จำกัดความลึก**: หยุดขยายที่ระยะ k (Pandemic, Border Extend, Connection)

### สิ่งที่การท่องกราฟบอกได้

| คำถาม | วิธี |
|---|---|
| จำนวน component | เริ่มท่องจากทุกจุดที่ยังไม่ไป นับจำนวนครั้งที่เริ่ม |
| มีวงรอบไหม (ไม่มีทิศ) | เพื่อนบ้านที่ไปแล้วซึ่งไม่ใช่ parent ใน BFS |
| component เป็นเส้นตรงไหม | ทุก degree ≤ 2 และจำนวนเส้น = จำนวนจุด − 1 |
| วงรอบของกราฟที่มีวงเดียว | ลอกใบ (degree 1) ออกจนหมด |
| ทางที่สั้นที่สุดระหว่างสองพื้นที่ | BFS หลายจุดเริ่มจากพื้นที่หนึ่งจนแตะอีกพื้นที่ |
