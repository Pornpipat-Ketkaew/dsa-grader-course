## Toolkit for this chapter

### Which algorithm?

| graph | algorithm | time |
|---|---|---|
| unweighted | BFS | O(n + m) |
| weights ≥ 0, dense (matrix, n ≤ ~3 000) | Dijkstra, array version | O(n²) |
| weights ≥ 0, sparse | Dijkstra with a binary heap | O(m log n) |
| negative weights, or negative-cycle test | Bellman–Ford | O(n · m) |
| all pairs, n ≤ ~400 | Floyd–Warshall | O(n³) |

### The ideas behind them

- **Relaxation**: `if (dist[u] + w < dist[v]) dist[v] = dist[u] + w`. Every algorithm here is relaxation in a clever order.
- **Dijkstra**: the unfinished vertex with the smallest distance is final. With a heap use **lazy deletion**: push duplicates, skip a popped entry whose distance is outdated.
- **Bellman–Ford**: n − 1 rounds of relaxing every edge; stop early when a round changes nothing. If round n still improves something, there is a **negative cycle**.
- **Floyd–Warshall**: after phase k, `dist[i][j]` is the best path using only stop-overs 1..k.

### Modelling tricks

| trick | example |
|---|---|
| vertex costs → edge weights (pay for the vertex you enter) | Columbia, Hacking, Buffet Flight |
| many sources → push all at distance 0 (a virtual source) | Hacking, Shortest Start |
| forbidden vertices → just do not add their edges | Closed City |
| products → sums with −log | Exchange |
| stop as soon as the target is popped (Dijkstra) | Closed City |

## ชุดเครื่องมือของบทนี้

### ใช้อัลกอริทึมไหน?

| กราฟ | อัลกอริทึม | เวลา |
|---|---|---|
| ไม่มีน้ำหนัก | BFS | O(n + m) |
| น้ำหนัก ≥ 0, หนาแน่น (เมทริกซ์, n ≤ ราว 3 000) | Dijkstra แบบอาร์เรย์ | O(n²) |
| น้ำหนัก ≥ 0, เบาบาง | Dijkstra ด้วย binary heap | O(m log n) |
| น้ำหนักติดลบ หรือตรวจวงรอบติดลบ | Bellman–Ford | O(n · m) |
| ทุกคู่, n ≤ ราว 400 | Floyd–Warshall | O(n³) |

### แนวคิดเบื้องหลัง

- **Relaxation**: `if (dist[u] + w < dist[v]) dist[v] = dist[u] + w` ทุกอัลกอริทึมในบทนี้คือ relaxation ในลำดับที่ฉลาด
- **Dijkstra**: จุดที่ยังไม่เสร็จซึ่งระยะน้อยที่สุดคือค่าสุดท้ายแล้ว เมื่อใช้ heap ให้ **ลบแบบช้า**: push ซ้ำได้ แล้วข้ามรายการที่ pop ออกมาแต่ระยะล้าสมัย
- **Bellman–Ford**: n − 1 รอบ แต่ละรอบ relax ทุกเส้น หยุดก่อนเมื่อรอบไหนไม่เปลี่ยนอะไร ถ้ารอบที่ n ยังปรับได้ แปลว่ามี **วงรอบติดลบ**
- **Floyd–Warshall**: หลังเฟส k ค่า `dist[i][j]` คือเส้นทางที่ดีที่สุดที่แวะได้แค่จุด 1..k

### เทคนิคการแปลงโจทย์

| เทคนิค | ตัวอย่าง |
|---|---|
| ค่าของจุด → น้ำหนักเส้น (จ่ายค่าจุดที่เดินเข้าไป) | Columbia, Hacking, Buffet Flight |
| หลายจุดเริ่ม → push ทุกจุดที่ระยะ 0 (จุดเริ่มเสมือน) | Hacking, Shortest Start |
| จุดต้องห้าม → ไม่ต้องใส่เส้นของมัน | Closed City |
| ผลคูณ → ผลบวกด้วย −log | Exchange |
| หยุดทันทีที่ pop เป้าหมาย (Dijkstra) | Closed City |
