## Toolkit for this chapter

All four techniques walk the data **once** (or once per line) while keeping a tiny summary of what was seen.

### Kadane (maximum subarray)

```cpp
best = -INF; endingHere = 0;
for (x : values) { endingHere = max(x, endingHere + x); best = max(best, endingHere); }
```

`endingHere` = best sum of a subarray that ends at the current element: either extend the previous one or start fresh. Apply it to any 1-D line, for example each diagonal of a matrix.

### Sweep line

Turn intervals into **events** (+1 at a start, −1 after an end), sort the events, and walk them in order keeping a counter. Questions about "how many intervals cover a point" or "where does the count change" become prefix sums over the events, and queries become binary searches over event positions.

### Two pointers

Two indices that only move in one direction each (both forward, or outward from a centre). Each moves at most n times, so the whole scan is O(n) even though it looks nested. Zuma expands outward from a run while the ends match.

### Ordered map of disjoint intervals

Keep non-overlapping intervals in a `map<start, end>`. A new interval finds its neighbours with `lower_bound` / `upper_bound`, swallows everything it overlaps, and is inserted once. Each interval is inserted once and erased at most once: amortised O(log n).

### How to recognise these problems

- "Best contiguous segment" → Kadane.
- Intervals, events, "at any moment" → sweep.
- "Expand while…" or "shrink while…" with monotone moves → two pointers.
- Painting / claiming ranges with merges → ordered map of intervals.

## ชุดเครื่องมือของบทนี้

ทั้งสี่เทคนิคเดินผ่านข้อมูล **รอบเดียว** (หรือรอบเดียวต่อแนว) พร้อมเก็บสรุปเล็ก ๆ ของสิ่งที่ผ่านมา

### Kadane (subarray ที่ผลรวมมากที่สุด)

```cpp
best = -INF; endingHere = 0;
for (x : values) { endingHere = max(x, endingHere + x); best = max(best, endingHere); }
```

`endingHere` = ผลรวมที่ดีที่สุดของ subarray ที่จบที่ตัวปัจจุบัน: ต่อจากอันก่อนหน้า หรือเริ่มใหม่ ใช้กับแนวหนึ่งมิติใดก็ได้ เช่นแต่ละแนวทแยงของเมทริกซ์

### Sweep line

เปลี่ยนช่วงเป็น **เหตุการณ์** (+1 ที่จุดเริ่ม, −1 หลังจุดจบ) เรียงเหตุการณ์ แล้วเดินตามลำดับพร้อมตัวนับ คำถามเรื่อง "มีกี่ช่วงครอบจุดนี้" หรือ "จำนวนเปลี่ยนที่ไหน" กลายเป็นผลรวมสะสมบนเหตุการณ์ และคำถามกลายเป็น binary search บนตำแหน่งเหตุการณ์

### Two pointers

ดัชนีสองตัวที่แต่ละตัวขยับทางเดียว (ไปข้างหน้าทั้งคู่ หรือออกจากจุดกลาง) แต่ละตัวขยับไม่เกิน n ครั้ง การไล่ทั้งหมดจึงเป็น O(n) แม้ดูเหมือนซ้อนกัน Zuma ขยายออกจากก้อนตราบที่ปลายทั้งสองเข้ากัน

### Ordered map ของช่วงที่ไม่ทับกัน

เก็บช่วงที่ไม่ทับกันใน `map<start, end>` ช่วงใหม่หาเพื่อนบ้านด้วย `lower_bound` / `upper_bound` กลืนทุกช่วงที่ทับ แล้วถูกใส่ครั้งเดียว แต่ละช่วงถูกใส่ครั้งเดียวและลบไม่เกินครั้งเดียว: เฉลี่ย O(log n)

### วิธีสังเกตโจทย์แบบนี้

- "ช่วงต่อเนื่องที่ดีที่สุด" → Kadane
- ช่วง เหตุการณ์ "ณ เวลาใด ๆ" → sweep
- "ขยายตราบที่…" หรือ "หดตราบที่…" ที่ขยับทางเดียว → two pointers
- การจอง/ระบายช่วงที่ต้องรวมกัน → ordered map ของช่วง
