## Toolkit for this chapter

### The backtracking template

```cpp
void search(int position) {
    if (position == n) { report(); return; }          // a complete answer
    for (each choice in increasing order) {
        if (!allowed(choice)) continue;               // prune as early as possible
        apply(choice);                                // choose
        search(position + 1);                         // explore
        undo(choice);                                 // un-choose
    }
}
```

- **Trying choices in increasing order** produces answers in dictionary order for free.
- **State in arrays** (`used[]`, `remaining[]`, column/diagonal flags) makes `allowed` O(1).
- **Undo exactly what apply did**, so the state is clean for the next choice.

### Kinds of search trees

| what is built | one level decides | example |
|---|---|---|
| subsets / combinations | take or skip item i | Barcode, Day Cover |
| strings over an alphabet | the letter at position i | Consecutive Ones, ABC Permutation |
| permutations | which unused value goes at position i | Permutation with Constraint |
| placements | where the i-th object goes | n-Queen, Tower Defense |
| paths | the next vertex | Map Walk, Path Sum |

### Making it fast

- **Feasibility pruning**: stop when the partial answer can no longer become valid (not enough positions left, a rule already broken).
- **Branch and bound** (optimisation): keep the best answer so far; stop a branch when even an optimistic estimate cannot beat it.
- **Good order**: try the most constrained decision first, and the most promising value first; break symmetries (for example, a new colour only as "the next unused one").

## ชุดเครื่องมือของบทนี้

### แม่แบบ backtracking

```cpp
void search(int position) {
    if (position == n) { report(); return; }          // คำตอบครบหนึ่งชุด
    for (แต่ละตัวเลือก เรียงจากน้อยไปมาก) {
        if (!allowed(choice)) continue;               // ตัดกิ่งให้เร็วที่สุด
        apply(choice);                                // เลือก
        search(position + 1);                         // สำรวจ
        undo(choice);                                 // ยกเลิก
    }
}
```

- **ลองตัวเลือกจากน้อยไปมาก** ได้คำตอบตามลำดับพจนานุกรมฟรี
- **เก็บสถานะในอาร์เรย์** (`used[]`, `remaining[]`, ธงคอลัมน์/แนวทแยง) ทำให้ `allowed` เป็น O(1)
- **ยกเลิกให้ตรงกับที่ apply ทำ** สถานะจึงสะอาดสำหรับตัวเลือกถัดไป

### ชนิดของต้นไม้ค้นหา

| สิ่งที่สร้าง | หนึ่งชั้นตัดสิน | ตัวอย่าง |
|---|---|---|
| เซตย่อย / combination | เอาหรือไม่เอาชิ้นที่ i | Barcode, Day Cover |
| สตริงบนชุดตัวอักษร | ตัวอักษรที่ตำแหน่ง i | Consecutive Ones, ABC Permutation |
| permutation | ค่าที่ยังไม่ใช้ตัวไหนอยู่ตำแหน่ง i | Permutation with Constraint |
| การวาง | ของชิ้นที่ i ไปอยู่ที่ไหน | n-Queen, Tower Defense |
| เส้นทาง | จุดถัดไป | Map Walk, Path Sum |

### ทำให้เร็ว

- **ตัดกิ่งที่เป็นไปไม่ได้**: หยุดเมื่อคำตอบบางส่วนไม่มีทางถูกได้อีก (ตำแหน่งเหลือไม่พอ กฎถูกละเมิดแล้ว)
- **Branch and bound** (หาค่าดีที่สุด): เก็บคำตอบที่ดีที่สุดไว้ หยุดกิ่งเมื่อแม้ประมาณการแบบมองโลกในแง่ดีก็ยังชนะไม่ได้
- **ลำดับที่ดี**: ลองการตัดสินใจที่ถูกจำกัดมากที่สุดก่อน และค่าที่น่าจะดีที่สุดก่อน ตัดความสมมาตร (เช่น สีใหม่ใช้ได้แค่ "สีถัดไปที่ยังไม่ใช้")
