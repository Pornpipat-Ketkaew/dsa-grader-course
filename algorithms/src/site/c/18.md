## Toolkit for this chapter

### Minimum spanning tree

A spanning tree connects all n vertices with n − 1 edges and no cycle. The cheapest one is found greedily, justified by the **cut property**: for any split of the vertices into two sides, the cheapest edge across the split belongs to some MST.

| algorithm | idea | time | best for |
|---|---|---|---|
| Prim, array | grow one tree; add the cheapest edge leaving it | O(n²) | dense or complete graphs, weights computed on the fly |
| Kruskal + DSU | sort edges; take each unless it closes a cycle | O(m log m) | edge lists |

### Union-find (DSU)

```cpp
int findRoot(int x) {
    while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }   // path halving
    return x;
}
// join: parent[findRoot(a)] = findRoot(b);
```

"Are a and b already connected?" = `findRoot(a) == findRoot(b)`, in almost O(1).

### Variations in this chapter

- **Maximum** spanning tree: reverse every comparison (sort decreasing, pick the largest link).
- **K pieces** instead of one tree: the cheapest forest with K trees is the MST without its K − 1 heaviest edges (stop Kruskal early).
- **Implicit complete graph**: when every pair is an edge with a formula weight, Prim's array version needs no stored weights.

## ชุดเครื่องมือของบทนี้

### ต้นไม้ทอดข้ามที่น้อยที่สุด

ต้นไม้ทอดข้ามเชื่อมทั้ง n จุดด้วย n − 1 เส้นและไม่มีวงรอบ ต้นที่ถูกที่สุดหาได้แบบโลภ โดยอาศัย **cut property**: ไม่ว่าแบ่งจุดเป็นสองฝั่งแบบไหน เส้นที่ถูกที่สุดที่ข้ามรอยแบ่งอยู่ใน MST สักต้นเสมอ

| อัลกอริทึม | แนวคิด | เวลา | เหมาะกับ |
|---|---|---|---|
| Prim แบบอาร์เรย์ | ขยายต้นไม้ต้นเดียว เพิ่มเส้นที่ถูกที่สุดที่ออกจากต้นไม้ | O(n²) | กราฟหนาแน่นหรือสมบูรณ์ น้ำหนักคำนวณตอนใช้ |
| Kruskal + DSU | เรียงเส้น เลือกทีละเส้นยกเว้นเส้นที่ปิดวงรอบ | O(m log m) | รายการเส้น |

### Union-find (DSU)

```cpp
int findRoot(int x) {
    while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }   // path halving
    return x;
}
// รวม: parent[findRoot(a)] = findRoot(b);
```

"a กับ b เชื่อมกันแล้วหรือยัง?" = `findRoot(a) == findRoot(b)` เกือบ O(1)

### รูปแบบที่ต่างไปในบทนี้

- ต้นไม้ทอดข้าม **ที่มากที่สุด**: กลับทุกการเปรียบเทียบ (เรียงจากมากไปน้อย เลือกเส้นเชื่อมที่ใหญ่ที่สุด)
- **K ชิ้น** แทนต้นไม้ต้นเดียว: ป่า K ต้นที่ถูกที่สุดคือ MST ที่ตัดเส้นที่หนักที่สุด K − 1 เส้นออก (หยุด Kruskal ก่อน)
- **กราฟสมบูรณ์แฝง**: เมื่อทุกคู่เป็นเส้นที่น้ำหนักมาจากสูตร Prim แบบอาร์เรย์ไม่ต้องเก็บน้ำหนัก
