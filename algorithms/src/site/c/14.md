## Toolkit for this chapter

### Five questions for every DP

1. **State**: what does `dp[i]` (or `dp[i][j]`) mean, in one sentence?
2. **Recurrence**: how is it built from smaller states? Usually "look at the last step / last item / last letters".
3. **Base cases**: the smallest states, filled by hand.
4. **Order**: fill so every state's dependencies are already final (increasing i, or increasing interval length).
5. **Answer**: which state (or max over states) is the result?

### Common shapes

| shape | state | example |
|---|---|---|
| 1-D sequence | dp[i] = answer for the first i | Fibonacci, Linear Recurrence, Chocolate |
| two sequences | dp[i][j] = answer for prefixes i and j | LCS |
| intervals | dp[l][r] = answer for the substring l..r | Hidden Palindrome |
| items × capacity | dp[w] = best / count with total w | 0-1 Subset Sum, SackKnap |
| grid / triangle | dp[row][col] from the cells it comes from | Number Triangle |

### Counting order matters

- **Ordered** compositions (1+2 ≠ 2+1): loop the total outside, the part size inside.
- **Unordered** (coin change): loop the part size outside, the total inside.
- **Each item at most once** (0/1 knapsack, one array): loop the capacity **downwards**.

### Memory

If row i only needs row i − 1, keep two rows (or one, with the right loop direction).

## ชุดเครื่องมือของบทนี้

### ห้าคำถามสำหรับ DP ทุกข้อ

1. **สถานะ**: `dp[i]` (หรือ `dp[i][j]`) หมายถึงอะไร ในหนึ่งประโยค?
2. **ความสัมพันธ์เวียนเกิด**: สร้างจากสถานะที่เล็กกว่าอย่างไร? มักเป็น "ดูก้าวสุดท้าย / ชิ้นสุดท้าย / ตัวอักษรตัวสุดท้าย"
3. **กรณีฐาน**: สถานะที่เล็กที่สุด เติมด้วยมือ
4. **ลำดับ**: เติมให้ทุกสถานะที่ต้องใช้เสร็จแล้วก่อน (i เพิ่มขึ้น หรือความยาวช่วงเพิ่มขึ้น)
5. **คำตอบ**: สถานะไหน (หรือ max ของสถานะใด) คือผลลัพธ์?

### รูปแบบที่พบบ่อย

| รูปแบบ | สถานะ | ตัวอย่าง |
|---|---|---|
| ลำดับหนึ่งมิติ | dp[i] = คำตอบของ i ตัวแรก | Fibonacci, Linear Recurrence, Chocolate |
| สองลำดับ | dp[i][j] = คำตอบของ prefix i และ j | LCS |
| ช่วง | dp[l][r] = คำตอบของสตริงย่อย l..r | Hidden Palindrome |
| ชิ้น × ความจุ | dp[w] = ดีที่สุด / จำนวนวิธี ที่ผลรวม w | 0-1 Subset Sum, SackKnap |
| ตาราง / สามเหลี่ยม | dp[row][col] จากช่องที่มาถึงมัน | Number Triangle |

### ลำดับของลูปสำคัญในการนับ

- **นับแบบสนลำดับ** (1+2 ≠ 2+1): ลูปผลรวมอยู่นอก ขนาดชิ้นอยู่ใน
- **นับแบบไม่สนลำดับ** (แลกเหรียญ): ลูปขนาดชิ้นอยู่นอก ผลรวมอยู่ใน
- **แต่ละชิ้นใช้ได้ครั้งเดียว** (0/1 knapsack อาร์เรย์เดียว): ลูปความจุ **จากมากไปน้อย**

### หน่วยความจำ

ถ้าแถว i ใช้แค่แถว i − 1 ให้เก็บสองแถว (หรือแถวเดียว ถ้าทิศของลูปถูก)
