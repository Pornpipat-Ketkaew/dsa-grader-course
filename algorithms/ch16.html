BFS (queue) and DFS (stack)

visited[start] = true; queue.push(start);
while (!queue.empty()) {
    int u = queue.front(); queue.pop();
    for (int v : adj[u]) if (!visited[v]) { visited[v] = true; distance[v] = distance[u] + 1; queue.push(v); }
}
  • Mark when pushing, so nothing enters twice.
  • BFS gives shortest distances in edges and visits by layers; DFS (the same code with a stack) is enough for reachability and components.
  • Multi-source BFS: push all sources at distance 0 first; every cell then gets its distance to the nearest source.
  • Depth limit: stop expanding at distance k (Pandemic, Border Extend, Connection).
