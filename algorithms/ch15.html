1Toolkit for this chapter

When "the first i items" is not enough

A plain dp[i] fails when the future depends on what the past was, not just how much of it there was: the last column used, the last two values, which door you came from, which sites are already visited. The fix is always the same:

add to the state exactly the part of the past that the next step needs, and nothing more.

problem extra state number of states
Table no 11 what the last column looks like (3 patterns) 3 per column
One Two Apart the last two values 9 per position
New Game Plus the last door used 4 per cell
Travelling Tourist the set of visited sites (a bitmask) and the current site 2^k · k

Method

  1. Write the transitions as a small state graph (which state can follow which).
  2. dp[i][state] = number of ways / best value of a prefix that ends in that state.
  3. Roll the arrays: only the previous layer is ever needed.

Bitmask DP

With k ≤ 15 or so, a subset fits in an int: bit j set = site j done. mask | (1 << j) adds a site, mask & (1 << j) tests one. Iterate masks in increasing order: every subset of a mask is smaller than it.

1ชุดเครื่องมือของบทนี้

เมื่อ "i ชิ้นแรก" ไม่พอ

dp[i] ธรรมดาใช้ไม่ได้เมื่ออนาคตขึ้นกับว่าอดีต เป็นอะไร ไม่ใช่แค่มีเท่าไร: คอลัมน์สุดท้ายที่ใช้ สองค่าสุดท้าย มาจากประตูไหน ไปสถานที่ไหนมาแล้วบ้าง วิธีแก้เหมือนเดิมเสมอ:

เพิ่มเข้าไปในสถานะ เฉพาะ ส่วนของอดีตที่ก้าวถัดไปต้องใช้ ไม่มากกว่านั้น

วิธีการ

  1. เขียนการเปลี่ยนสถานะเป็น กราฟสถานะ เล็ก ๆ (สถานะไหนตามหลังสถานะไหนได้)
  2. dp[i][state] = จำนวนวิธี / ค่าที่ดีที่สุด ของ prefix ที่จบในสถานะนั้น
  3. ใช้อาร์เรย์หมุนเวียน: ต้องใช้แค่ชั้นก่อนหน้า

Bitmask DP

เมื่อ k ≤ ราว 15 เซตย่อยใส่ใน int ได้: บิต j เป็น 1 = ไปสถานที่ j แล้ว mask | (1 << j) เพิ่มสถานที่ mask & (1 << j) ตรวจหนึ่งแห่ง วน mask จากน้อยไปมาก: ทุกเซตย่อยของ mask มีค่าน้อยกว่ามัน
