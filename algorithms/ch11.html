Recursion & backtrackingRecursion และ Backtracking

Build the answer one choice at a time; undo the choice; prune dead branches.

สร้างคำตอบทีละตัวเลือก ย้อนกลับเมื่อเสร็จ และตัดกิ่งที่ไปต่อไม่ได้

★Problems in this chapterโจทย์ในบทนี้

ex00e4Generate Barcodeสร้างบาร์โค้ด (Generate Barcode)★☆☆Decide the B characters left to right; at each position try '0' and '1', but only if the remaining positions can still end with exactly A ones. Every leaf of the pruned tree is a valid barcode.ตัดสินใจตัวอักษร B ตัวจากซ้ายไปขวา ที่แต่ละตำแหน่งลอง '0' และ '1' แต่เฉพาะเมื่อตำแหน่งที่เหลือยังจบด้วย 1 จำนวน A ตัวพอดีได้ ทุกใบของต้นไม้ที่ตัดกิ่งแล้วคือบาร์โค้ดที่ถูกต้องex00e5Consecutive Onesเลข 1 ติดกัน (Consecutive Ones)★☆☆Enumerate all n-bit strings in increasing order ('0' before '1' at every depth) and carry two small facts down the recursion: the length of the current run of 1s and whether a run of k was already seen.ไล่ทุกสตริง n บิตตามลำดับจากน้อยไปมาก ('0' ก่อน '1' ทุกระดับ) และส่งข้อมูลเล็ก ๆ สองอย่างลงไปใน recursion: ความยาวของเลข 1 ที่ติดกันอยู่ตอนนี้ และเคยเจอ 1 ติดกัน k ตัวแล้วหรือยังda67_f_abc_permutationABC Permutationเรียงสับเปลี่ยน ABC★★☆Fill the N positions left to right; at each position try A, B, C in alphabetical order if that letter still has copies left. Alphabetical order at every level gives dictionary order of the whole strings, and the count is known only at the end, so buffer the lines.เติม N ตำแหน่งจากซ้ายไปขวา ที่แต่ละตำแหน่งลอง A, B, C ตามลำดับตัวอักษรถ้าตัวนั้นยังมีเหลือ การเรียงตามตัวอักษรทุกระดับให้ลำดับพจนานุกรมของทั้งสตริง และรู้จำนวนตอนจบเท่านั้น จึงเก็บบรรทัดไว้ก่อนda68_f_abcd_permutationABCD Permutationเรียงสับเปลี่ยน ABCD★★☆Same skeleton as ABC Permutation with four letters: at each of the N positions try A, B, C, D in order while that letter has copies left (at most a, b, c, d). Buffer the strings, then print the count and the buffer.โครงเดียวกับ ABC Permutation แต่มีสี่ตัวอักษร: ที่แต่ละตำแหน่งจาก N ตำแหน่ง ลอง A, B, C, D ตามลำดับตราบที่ตัวนั้นยังเหลือ (ไม่เกิน a, b, c, d) เก็บสตริงไว้ แล้วพิมพ์จำนวนตามด้วยบัฟเฟอร์da66_f1_map_walkMap Walkเดินบนแผนที่ (Map Walk)★★☆Depth-first search from (1,1) that tries the moves in the order A (right), B (down), C (up), marks a cell visited on entry and unmarks it on return. Every arrival at (R,C) prints the current command string, already in alphabetical order.DFS จาก (1,1) ที่ลองการเดินตามลำดับ A (ขวา), B (ลง), C (ขึ้น) ทำเครื่องหมายช่องเมื่อเข้าและลบเมื่อกลับ ทุกครั้งที่ถึง (R,C) ให้พิมพ์สตริงคำสั่งปัจจุบัน ซึ่งเรียงตามตัวอักษรอยู่แล้วex07e1_nqueenn-Queenn ราชินี (n-Queen)★★☆Put exactly one queen per row, so rows never clash. Columns and both diagonal directions are tracked by three boolean arrays indexed by column, row+column and row−column+n−1, making "is this square attacked?" O(1).วางราชินีแถวละหนึ่งตัวพอดี แถวจึงไม่มีทางชนกัน ส่วนคอลัมน์และแนวทแยงทั้งสองทิศติดตามด้วยอาร์เรย์ boolean สามตัวที่ใช้ดัชนี column, row+column และ row−column+n−1 ทำให้ "ช่องนี้ถูกโจมตีไหม?" เป็น O(1)a64_q1_permu_beforePermutation with Constraintการเรียงสับเปลี่ยนที่มีเงื่อนไขก่อนหลัง★★☆Generate permutations in lexicographic order by trying values 0..n−1 at each position, and refuse to place b while its required predecessor a is not yet placed. The rule is checked the moment it could break, so no dead branch survives a single step.สร้าง permutation ตามลำดับพจนานุกรมโดยลองค่า 0..n−1 ที่แต่ละตำแหน่ง และไม่ยอมวาง b ถ้าตัวที่ต้องมาก่อน (a) ยังไม่ถูกวาง กฎถูกตรวจทันทีที่มีโอกาสผิด กิ่งที่ผิดจึงไม่รอดเกินหนึ่งก้าวa65_q1_tower_defenseTower DefenseTower Defense (ป้อมปืน)★★★Each useful hit lowers the total power by exactly 1, so the task is "maximize useful hits". Give every tower a target in turn (any monster in range that still has power, or no useful hit) and cut a branch as soon as hits + remaining towers cannot beat the best found.การยิงที่มีผลแต่ละครั้งลดพลังรวมได้ 1 พอดี โจทย์จึงกลายเป็น "ทำให้ยิงได้ผลมากที่สุด" ให้ป้อมแต่ละป้อมเลือกเป้าทีละป้อม (มอนสเตอร์ในระยะที่ยังมีพลัง หรือไม่ยิงโดนอะไรที่มีผล) และตัดกิ่งทันทีที่ hits + จำนวนป้อมที่เหลือ ไม่มีทางชนะค่าที่ดีที่สุดที่เจอแล้วa66_q1a_day_coverDay CoverDay Cover (ครอบคลุมทุกวัน)★★★Each student is either invited or skipped, so the search tree is the 2^m subsets. Cut a branch once it already uses as many students as the best answer, and stop a branch the moment every day is covered. A bitset per student makes "add this student's days" one OR.นิสิตแต่ละคนถูกเชิญหรือถูกข้าม ต้นไม้ค้นหาจึงเป็นเซตย่อยทั้ง 2^m แบบ ตัดกิ่งเมื่อจำนวนคนที่ใช้เท่ากับคำตอบที่ดีที่สุดแล้ว และหยุดกิ่งทันทีที่ครอบคลุมทุกวัน bitset ของนิสิตแต่ละคนทำให้ "เพิ่มวันของนิสิตคนนี้" เป็นการ OR ครั้งเดียวex07e3_coloringGraph Coloringระบายสีกราฟ (Graph Coloring)★★★Color one vertex per level. Reuse any color no neighbor has, or open exactly one new color, since unused colors are interchangeable. Always color next the vertex that already sees the most different colors, and cut any branch that uses as many colors as the best coloring found.ระบายจุดละหนึ่งระดับ ใช้สีเดิมที่ไม่มีเพื่อนบ้านใช้ หรือเปิดสีใหม่เพียงสีเดียว เพราะสีที่ยังไม่ใช้ทุกสีเหมือนกัน เลือกระบายจุดที่เห็นสีต่างกันมากที่สุดก่อนเสมอ และตัดทุกกิ่งที่ใช้สีเท่ากับการระบายที่ดีที่สุดที่เจอแล้วa64_q4_path_sumPath Sumผลรวมบนเส้นทาง (Path Sum)★★★Enumerate simple paths from every start node by DFS with an onPath mark, answering all 8 queries in the same search. A path's weight only grows and can grow by at most the sum of the heaviest edges of the nodes not on it, so cut as soon as no open query lies in that range; stop everything once all 8 are YES.แจกแจง simple path จากทุกจุดเริ่มด้วย DFS ที่มีเครื่องหมาย onPath และตอบทั้ง 8 คำถามในการค้นหาเดียวกัน น้ำหนักของเส้นทางมีแต่เพิ่มขึ้น และเพิ่มได้ไม่เกินผลรวมเส้นที่หนักที่สุดของจุดที่ยังไม่อยู่บนเส้นทาง จึงตัดทันทีที่ไม่มีคำถามที่ยังเปิดอยู่ในช่วงนั้น และหยุดทั้งหมดเมื่อทั้ง 8 ข้อเป็น YES

1Toolkit for this chapter

The backtracking template

void search(int position) {
    if (position == n) { report(); return; }          // a complete answer
    for (each choice in increasing order) {
        if (!allowed(choice)) continue;               // prune as early as possible
        apply(choice);                                // choose
        search(position + 1);                         // explore
        undo(choice);                                 // un-choose
    }
}
  • Trying choices in increasing order produces answers in dictionary order for free.
  • State in arrays (used[], remaining[], column/diagonal flags) makes allowed O(1).
  • Undo exactly what apply did, so the state is clean for the next choice.

Kinds of search trees

what is built one level decides example
subsets / combinations take or skip item i Barcode, Day Cover
strings over an alphabet the letter at position i Consecutive Ones, ABC Permutation
permutations which unused value goes at position i Permutation with Constraint
placements where the i-th object goes n-Queen, Tower Defense
paths the next vertex Map Walk, Path Sum

Making it fast

  • Feasibility pruning: stop when the partial answer can no longer become valid (not enough positions left, a rule already broken).
  • Branch and bound (optimisation): keep the best answer so far; stop a branch when even an optimistic estimate cannot beat it.
  • Good order: try the most constrained decision first, and the most promising value first; break symmetries (for example, a new colour only as "the next unused one").

แม่แบบ backtracking

void search(int position) {
    if (position == n) { report(); return; }          // คำตอบครบหนึ่งชุด
    for (แต่ละตัวเลือก เรียงจากน้อยไปมาก) {
        if (!allowed(choice)) continue;               // ตัดกิ่งให้เร็วที่สุด
        apply(choice);                                // เลือก
        search(position + 1);                         // สำรวจ
        undo(choice);                                 // ยกเลิก
    }
}
  • ลองตัวเลือกจากน้อยไปมาก ได้คำตอบตามลำดับพจนานุกรมฟรี
  • เก็บสถานะในอาร์เรย์ (used[], remaining[], ธงคอลัมน์/แนวทแยง) ทำให้ allowed เป็น O(1)
  • ยกเลิกให้ตรงกับที่ apply ทำ สถานะจึงสะอาดสำหรับตัวเลือกถัดไป

ชนิดของต้นไม้ค้นหา

สิ่งที่สร้าง หนึ่งชั้นตัดสิน ตัวอย่าง
เซตย่อย / combination เอาหรือไม่เอาชิ้นที่ i Barcode, Day Cover
สตริงบนชุดตัวอักษร ตัวอักษรที่ตำแหน่ง i Consecutive Ones, ABC Permutation
permutation ค่าที่ยังไม่ใช้ตัวไหนอยู่ตำแหน่ง i Permutation with Constraint

เส้นทาง จุดถัดไป Map Walk, Path Sum

ทำให้เร็ว

  • ตัดกิ่งที่เป็นไปไม่ได้: หยุดเมื่อคำตอบบางส่วนไม่มีทางถูกได้อีก (ตำแหน่งเหลือไม่พอ กฎถูกละเมิดแล้ว)
  • Branch and bound (หาค่าดีที่สุด): เก็บคำตอบที่ดีที่สุดไว้ หยุดกิ่งเมื่อแม้ประมาณการแบบมองโลกในแง่ดีก็ยังชนะไม่ได้
  • ลำดับที่ดี: ลองการตัดสินใจที่ถูกจำกัดมากที่สุดก่อน และค่าที่น่าจะดีที่สุดก่อน ตัดความสมมาตร (เช่น สีใหม่ใช้ได้แค่ "สีถัดไปที่ยังไม่ใช้")
