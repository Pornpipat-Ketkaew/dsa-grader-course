Five fresh problems, each one textbook technique with a twist.

69_AGWARMColoring BookColoring Book (สมุดระบายสี)★☆☆Every region needs its own color, so the answer is the number of regions: connected components of the grid where two neighbouring cells are joined unless a wall separates them. Each wall is stored in only one of its two cells, so each direction reads its bit from the right cell.แต่ละพื้นที่ต้องมีสีของตัวเอง คำตอบจึงเป็นจำนวนพื้นที่: connected component ของตารางที่ช่องข้างกันเชื่อมกัน ยกเว้นมีขอบกั้น ขอบแต่ละเส้นถูกเก็บไว้ในช่องเดียวจากสองช่อง แต่ละทิศจึงต้องอ่านบิตจากช่องที่ถูกต้อง69_AG1BraceletBracelet (สร้อยข้อมือ)★★☆Generate every arrangement of N beads in dictionary order with a remaining[] count per letter (the permutation generator with counts). A bracelet and its flip are the same, so print an arrangement only when it is ≤ its reverse: that picks exactly one of each pair, and a palindrome once.สร้างทุกการเรียงลูกปัด N เม็ดตามลำดับพจนานุกรม โดยมี remaining[] นับจำนวนที่เหลือของแต่ละตัวอักษร (ตัวสร้าง permutation แบบมีจำนวน) สร้อยกับตัวที่พลิกแล้วคือแบบเดียวกัน จึงพิมพ์การเรียงเฉพาะเมื่อมัน ≤ ตัวกลับด้าน ซึ่งเลือกหนึ่งตัวจากแต่ละคู่พอดี และ palindrome ครั้งเดียว69_AG2Eternal Merit (3 × N dominoes)Eternal Merit (ปูกระเบื้อง 3 × N)★★★A full 3 × w board cannot always be split into smaller full boards: dominoes can stick out. So count two shapes: F(w) = full 3 × w board, G(w) = 3 × w board with its top-right cell missing. Looking at how the last column is covered gives F(w) = F(w − 2) + 2·G(w − 1) and G(w) = F(w − 1) + G(w − 2).กระดาน 3 × w ที่เต็มไม่ได้แบ่งเป็นกระดานเต็มที่เล็กกว่าได้เสมอ: โดมิโนอาจยื่นออกมา จึงนับสองรูปแบบ: F(w) = กระดาน 3 × w ที่เต็ม, G(w) = กระดาน 3 × w ที่ขาดช่องมุมขวาบน ดูว่าคอลัมน์สุดท้ายถูกปูอย่างไร จะได้ F(w) = F(w − 2) + 2·G(w − 1) และ G(w) = F(w − 1) + G(w − 2)69_AG3ZiplineZipline (ซิปไลน์)★★☆One connected network with no loop is a spanning tree, and the longest total wire is a maximum spanning tree. Each wire's length is √(D² + (Hᵢ − Hⱼ)²). Kruskal with the edges sorted longest first builds it.เครือข่ายเดียวที่เชื่อมกันและไม่มีวงวนคือต้นไม้ทอดข้าม และลวดรวมยาวที่สุดคือต้นไม้ทอดข้ามที่มากที่สุด ความยาวลวดแต่ละเส้นคือ √(D² + (Hᵢ − Hⱼ)²) Kruskal ที่เรียงเส้นจากยาวไปสั้นสร้างมันได้69_AG4Portal 3Portal 3★★★Where you can go next depends on the room and on how many shots are left, so make that pair the vertex: (used, room). Each tunnel becomes two edges: walk it (same layer, its time) or shoot through it (next layer, time 0). Dijkstra on these (K + 1)·N states; the answer is the first exit state popped.ที่ที่ไปต่อได้ขึ้นกับห้องและจำนวนกระสุนที่เหลือ จึงใช้คู่นั้นเป็นจุดยอด: (used, room) ทางเชื่อมแต่ละเส้นกลายเป็นสองเส้น: เดิน (ชั้นเดิม เสียเวลาของมัน) หรือยิงทะลุ (ชั้นถัดไป เวลา 0) รัน Dijkstra บน (K + 1)·N สถานะ คำตอบคือสถานะทางออกตัวแรกที่ถูก pop

1How to read this mock exam

Each problem is one technique from an earlier chapter with one twist. In an exam, the fastest route is to name the technique first, then handle the twist:

problem technique (chapter) the twist
Coloring Book components by flood fill (16) each wall is stored in only one of its two cells
Bracelet backtracking over a multiset (11) keep a string only if it is ≤ its reverse
Eternal Merit DP with states (15) a second shape (a board with a missing corner)
Zipline Kruskal (18) maximum tree, 3-D lengths
Portal 3 Dijkstra (17) state = (room, shots used): a layered graph

A checklist that catches most mistakes

  • Sizes: does any value or answer exceed 2³¹? Then long long.
  • Input format: unsorted lists, 1-based labels, digits written without spaces.
  • Edge cases: n = 1, empty answers ("print 0"), odd sizes.
  • Before coding a greedy or a shortcut, try a small counterexample.

1วิธีอ่านข้อสอบเสมือนจริงชุดนี้

แต่ละข้อคือเทคนิคหนึ่งจากบทก่อน ๆ ที่บิดหนึ่งจุด ในห้องสอบ ทางที่เร็วที่สุดคือบอกชื่อเทคนิคให้ได้ก่อน แล้วค่อยจัดการจุดที่บิด:

โจทย์ เทคนิค (บท) จุดที่บิด
Coloring Book component ด้วย flood fill (16) ขอบแต่ละเส้นเก็บไว้ในช่องเดียวจากสองช่อง
Bracelet backtracking บน multiset (11) เก็บสตริงเฉพาะเมื่อ ≤ ตัวกลับด้าน
Eternal Merit DP มีสถานะ (15) รูปทรงที่สอง (กระดานที่ขาดมุม)
Zipline Kruskal (18) ต้นไม้ที่มากที่สุด ความยาวสามมิติ
Portal 3 Dijkstra (17) สถานะ = (ห้อง, จำนวนครั้งที่ยิง): กราฟหลายชั้น

รายการตรวจที่จับความผิดพลาดส่วนใหญ่ได้

  • ขนาด: มีค่าหรือคำตอบไหนเกิน 2³¹ ไหม? ถ้ามีใช้ long long
  • รูปแบบข้อมูล: รายการที่ไม่เรียง ป้ายเริ่มจาก 1 ตัวเลขที่เขียนติดกันไม่มีช่องว่าง
  • กรณีขอบ: n = 1 คำตอบว่าง ("พิมพ์ 0") ขนาดคี่
  • ก่อนเขียน greedy หรือทางลัด ลองหาตัวอย่างค้านเล็ก ๆ
