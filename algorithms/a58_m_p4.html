a58_m_p4

Class Selection (midterm version)เลือกวิชาเรียน (ฉบับข้อสอบกลางภาค)

Greedy (interval scheduling)Choosing the right greedy ruleCounterexamplesGreedy (interval scheduling)เลือกกฎ greedy ให้ถูกตัวอย่างค้านO(N log N) time · O(N) memory★☆☆

This exam problem is the same task as Class Selection, so the same earliest-finish greedy solves it. The real lesson is how to reject the other tempting rules: each of earliest start, shortest duration and fewest overlaps has a small input where it loses.

ข้อสอบข้อนี้เป็นโจทย์เดียวกับ Class Selection จึงแก้ด้วย greedy แบบจบเร็วที่สุดก่อนเหมือนกัน บทเรียนจริงคือวิธีปฏิเสธกฎอื่นที่ดูน่าใช้: เริ่มเร็วที่สุด สั้นที่สุด และทับน้อยที่สุด ต่างก็มีอินพุตเล็ก ๆ ที่ทำให้แพ้

1Technique: pick the greedy rule, then try to break it

The problem PDF in this folder is identical to Class Selection; read that page for the algorithm and the exchange-argument proof. This page trains the step that comes before a proof in an exam: when several greedy orders look plausible, test each one on tiny inputs and throw away every rule that loses even once.

2How it maps onto this problem

Step 1: four candidate rules

Every candidate has the same shape: sort the classes by some key, then keep each class that overlaps nothing kept so far. Only the key changes.

rule (key) idea behind it
earliest finish free the room as early as possible
earliest start start using the room as early as possible
shortest duration short classes block less time
fewest overlaps classes that clash with few others are "cheap"

Step 2: break the wrong ones

earliest start:   [0..........10]          picks the long class first  → 1
                    [1-2] [3-4] [5-6]       optimal                     → 3

shortest:         [0-----5]   [5-----10]    optimal                     → 2
                        [4-6]               shortest is taken first     → 1

fewest overlaps:  [0-2][2-4][4-6][6-8]      optimal (top row)           → 4
                    [1-3]x3 [3-5] [5-7]x3   [3-5] has the fewest clashes,
                                            taking it blocks two tops   → 3

Run all four rules on each preset below and watch which one survives.

Step 3: the survivor

Only earliest finish wins on every input, and the exchange argument on the Class Selection page proves it always will. The solution below is that greedy.

Exam habit

Before coding a greedy, spend two minutes on 3- or 4-interval counterexamples for each candidate rule. A rule that survives is not yet proven, but a rule that fails is certainly wrong.

3Solution

main.cpp⬇ .cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<pair<int, int>> classes(n);       // (finish, start): sorting orders by finish time
    // index = 0..n-1: the n start times
    for (int index = 0; index < n; index++) cin >> classes[index].second;
    // index = 0..n-1: the n finish times
    for (int index = 0; index < n; index++) cin >> classes[index].first;
    sort(classes.begin(), classes.end());    // earliest finish first

    int chosen = 0;
    int lastFinish = INT_MIN;                // finish time of the last chosen class (none yet)
    // index = 0..n-1 in order of finish time: keep a class if it starts after the last kept one ends
    for (int index = 0; index < n; index++) {
        if (classes[index].second >= lastFinish) {
            chosen++;
            lastFinish = classes[index].first;
        }
    }
    cout << chosen << '\n';
}

1เทคนิค: เลือกกฎ greedy แล้วลองทำให้มันพัง

PDF ในโฟลเดอร์นี้เหมือนกับ Class Selection ทุกตัวอักษร อ่านหน้านั้นสำหรับอัลกอริทึมและการพิสูจน์แบบ exchange argument หน้านี้ฝึกขั้นที่มา ก่อน การพิสูจน์ในห้องสอบ: เมื่อมีลำดับ greedy หลายแบบที่ดูเป็นไปได้ ให้ทดสอบแต่ละแบบด้วยอินพุตเล็ก ๆ และทิ้งทุกกฎที่แพ้แม้แต่ครั้งเดียว

2นำมาใช้กับโจทย์นี้อย่างไร

ขั้นที่ 1: กฎที่เป็นตัวเลือกสี่แบบ

ทุกตัวเลือกมีรูปแบบเดียวกัน: เรียงวิชาตาม key บางอย่าง แล้วเก็บทุกวิชาที่ไม่ทับกับวิชาที่เก็บไว้แล้ว ต่างกันแค่ key

กฎ (key) แนวคิด
จบ เร็วที่สุด ปล่อยห้องให้ว่างเร็วที่สุด
เริ่ม เร็วที่สุด เริ่มใช้ห้องให้เร็วที่สุด
สั้น ที่สุด วิชาสั้นกินเวลาน้อย
ทับน้อย ที่สุด วิชาที่ชนกับวิชาอื่นน้อย "ราคาถูก"

ขั้นที่ 2: ทำให้กฎที่ผิดพัง

เริ่มเร็วสุด:      [0..........10]          เลือกวิชายาวก่อน             → 1
                    [1-2] [3-4] [5-6]       ดีที่สุด                     → 3

สั้นที่สุด:        [0-----5]   [5-----10]    ดีที่สุด                     → 2
                        [4-6]               วิชาสั้นสุดถูกเลือกก่อน       → 1

ทับน้อยที่สุด:     [0-2][2-4][4-6][6-8]      ดีที่สุด (แถวบน)              → 4
                    [1-3]x3 [3-5] [5-7]x3   [3-5] ชนน้อยที่สุด
                                            เลือกมันแล้วบังแถวบนสองวิชา  → 3

ลองรันทั้งสี่กฎบนแต่ละ preset ด้านล่าง แล้วดูว่ากฎไหนรอด

ขั้นที่ 3: กฎที่รอด

มีเพียง จบเร็วที่สุด ที่ชนะทุกอินพุต และ exchange argument ในหน้า Class Selection พิสูจน์ว่าจะชนะเสมอ โค้ดด้านล่างคือ greedy นั้น

นิสัยในห้องสอบ

ก่อนเขียน greedy ใช้เวลาสองนาทีหาตัวอย่างค้าน 3–4 ช่วงสำหรับกฎแต่ละแบบ กฎที่รอดยังไม่ถือว่าพิสูจน์แล้ว แต่กฎที่แพ้ผิดแน่นอน
