da67_f_one_two_apart

One Two ApartOne Two Apart (1 กับ 2 ต้องห่างกัน)

DP with states (last two values)Transition by a local ruleDP แบบมีสถานะ (สองค่าสุดท้าย)เปลี่ยนสถานะตามกฎเฉพาะที่O(27 n) time · O(1) memory★★★

A new value must not clash with the values one and two positions back, so the state is the pair (previous, last). Count arrays per pair; append value v to (previous, last) when v clashes with neither, landing in state (last, v). Nine states, 27 checks per step.

ค่าใหม่ต้องไม่ชนกับค่าที่อยู่ก่อนหน้าหนึ่งและสองตำแหน่ง สถานะจึงเป็นคู่ (previous, last) นับอาร์เรย์แยกตามคู่ ต่อค่า v หลัง (previous, last) เมื่อ v ไม่ชนกับทั้งสองตัว แล้วไปอยู่ที่สถานะ (last, v) มี 9 สถานะ ตรวจ 27 ครั้งต่อก้าว

1Technique: choosing the state from the rule's reach

The rule "a 1 and a 2 may not be within distance 2" looks two cells back. So when appending a value, we must know the last two values, and nothing earlier matters. In general:

rule reaches k positions back ⇒ state = the last k values (3^k states here).

Then it is the same machinery as Table no 11: count per state, step by step.

2How it maps onto this problem

Step 1: state and start

ways[previous][last] = number of valid arrays of the current length ending with previous, last. For length 2 every pair is allowed except 1,2 and 2,1: 7 arrays, matching the PDF. n = 1 is handled separately (3 arrays).

Step 2: transition

For each state (previous, last) and each new value:

if value clashes neither with previous (distance 2) nor with last (distance 1), then next[last][value] += ways[previous][last].

Pairs already inside the state were checked when they were created, so they never need re-checking.

Step 3: totals and modulo

The answer is the sum of all nine counts. Every addition is taken mod 100 000 007; values stay below 2·10⁸, safe in long long.

Traps
  • Checking only the neighbor (distance 1) misses the "two apart" half: n = 3 would print 17 instead of 15 (it would allow 102 and 201).
  • 1,1 and 2,2 and anything with 0 are fine; only 1–2 pairs clash.

3Solution

main.cpp⬇ .cpp
#include <iostream>
using namespace std;

const long long MOD = 100000007;

// a 1 and a 2 clash when they are at distance 1 or 2
bool clash(int a, int b) {
    return (a == 1 && b == 2) || (a == 2 && b == 1);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    if (n == 1) {                                   // 0, 1, 2
        cout << 3 << '\n';
        return 0;
    }
    // ways[previous][last] = valid arrays of the current length ending with these two values
    long long ways[3][3];
    // previous, last = 0..2: length 2, every pair except 1-2 and 2-1
    for (int previous = 0; previous < 3; previous++)
        for (int last = 0; last < 3; last++) ways[previous][last] = clash(previous, last) ? 0 : 1;
    // length = 3..n: append one value to every array of length length-1
    for (int length = 3; length <= n; length++) {
        long long next[3][3] = {};
        // previous, last = old last two values; value = the new one (all 0..2)
        for (int previous = 0; previous < 3; previous++)
            for (int last = 0; last < 3; last++)
                for (int value = 0; value < 3; value++)
                    if (!clash(previous, value) && !clash(last, value))
                        next[last][value] = (next[last][value] + ways[previous][last]) % MOD;
        // previous, last = 0..2: the new table replaces the old one
        for (int previous = 0; previous < 3; previous++)
            for (int last = 0; last < 3; last++) ways[previous][last] = next[previous][last];
    }
    long long total = 0;
    // previous, last = 0..2: add up every possible ending
    for (int previous = 0; previous < 3; previous++)
        for (int last = 0; last < 3; last++) total = (total + ways[previous][last]) % MOD;
    cout << total << '\n';
}

1เทคนิค: เลือกสถานะจากระยะที่กฎมองไปถึง

กฎ "1 กับ 2 ห้ามอยู่ห่างกันไม่เกิน 2" มองย้อนไป สองช่อง ตอนต่อค่าใหม่เราจึงต้องรู้ค่า สองตัว สุดท้าย และค่าก่อนหน้านั้นไม่มีผล โดยทั่วไป:

กฎมองย้อนไป k ตำแหน่ง ⇒ สถานะ = k ค่าสุดท้าย (ในข้อนี้มี 3^k สถานะ)

จากนั้นก็เป็นกลไกเดียวกับ Table no 11: นับแยกตามสถานะ ทีละก้าว

2นำมาใช้กับโจทย์นี้อย่างไร

ขั้นที่ 1: สถานะและจุดเริ่ม

ways[previous][last] = จำนวนอาร์เรย์ที่ถูกต้องในความยาวปัจจุบันที่จบด้วย previous, last เมื่อยาว 2 ทุกคู่ใช้ได้ยกเว้น 1,2 และ 2,1: 7 แบบ ตรงกับ PDF ส่วน n = 1 แยกกรณีไว้ (3 แบบ)

ขั้นที่ 2: การเปลี่ยนสถานะ

สำหรับแต่ละสถานะ (previous, last) และค่าใหม่ value:

ถ้า value ไม่ชนกับ previous (ระยะ 2) และไม่ชนกับ last (ระยะ 1) แล้ว next[last][value] += ways[previous][last]

คู่ที่อยู่ในสถานะแล้วถูกตรวจไปตอนสร้าง จึงไม่ต้องตรวจซ้ำ

ขั้นที่ 3: ผลรวมและมอดุโล

คำตอบคือผลรวมของทั้งเก้าค่า ทุกการบวก mod 100 000 007 ค่าไม่เกิน 2·10⁸ ปลอดภัยใน long long

กับดัก
  • ตรวจแค่ตัวที่ติดกัน (ระยะ 1) จะพลาดครึ่ง "ห่างสองช่อง": n = 3 จะพิมพ์ 17 แทน 15 (ยอมให้ 102 และ 201)
  • 1,1 และ 2,2 และทุกคู่ที่มี 0 ใช้ได้ มีแค่คู่ 1–2 ที่ชนกัน

3โค้ดเฉลย

main.cpp⬇ .cpp
#include <iostream>
using namespace std;

const long long MOD = 100000007;

// a 1 and a 2 clash when they are at distance 1 or 2
bool clash(int a, int b) {
    return (a == 1 && b == 2) || (a == 2 && b == 1);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    if (n == 1) {                                   // 0, 1, 2
        cout << 3 << '\n';
        return 0;
    }
    // ways[previous][last] = valid arrays of the current length ending with these two values
    long long ways[3][3];
    // previous, last = 0..2: length 2, every pair except 1-2 and 2-1
    for (int previous = 0; previous < 3; previous++)
        for (int last = 0; last < 3; last++) ways[previous][last] = clash(previous, last) ? 0 : 1;
    // length = 3..n: append one value to every array of length length-1
    for (int length = 3; length <= n; length++) {
        long long next[3][3] = {};
        // previous, last = old last two values; value = the new one (all 0..2)
        for (int previous = 0; previous < 3; previous++)
            for (int last = 0; last < 3; last++)
                for (int value = 0; value < 3; value++)
                    if (!clash(previous, value) && !clash(last, value))
                        next[last][value] = (next[last][value] + ways[previous][last]) % MOD;
        // previous, last = 0..2: the new table replaces the old one
        for (int previous = 0; previous < 3; previous++)
            for (int last = 0; last < 3; last++) ways[previous][last] = next[previous][last];
    }
    long long total = 0;
    // previous, last = 0..2: add up every possible ending
    for (int previous = 0; previous < 3; previous++)
        for (int last = 0; last < 3; last++) total = (total + ways[previous][last]) % MOD;
    cout << total << '\n';
}
