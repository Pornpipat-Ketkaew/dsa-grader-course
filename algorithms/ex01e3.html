Binary Search NearBinary Search Near (ค้นหาค่าที่ใกล้ที่สุดไม่เกิน x)

Binary search with an invariant (left ≤ x < right)Imaginary ends −1 and nBinary search ด้วยเงื่อนไขคงที่ (left ≤ x < right)ปลายสมมติ −1 และ nO(N + M log N) time · O(N) memory★☆☆

The array splits into a left part (values ≤ x) and a right part (values > x). Keep left inside the first part and right inside the second, starting from the imaginary positions −1 and n; halve the gap until they are neighbours. The answer is A[left], or −1 when left never moved.

อาร์เรย์แบ่งเป็นส่วนซ้าย (ค่า ≤ x) และส่วนขวา (ค่า > x) ให้ left อยู่ในส่วนแรกและ right อยู่ในส่วนที่สอง เริ่มจากตำแหน่งสมมติ −1 และ n แล้วแบ่งครึ่งช่องว่างจนทั้งสองติดกัน คำตอบคือ A[left] หรือ −1 ถ้า left ไม่เคยขยับ

1Technique: binary search on a boundary, with an invariant

Every binary search in this course is the same idea: a monotone yes/no question over a sorted range ("is A[i] ≤ x?" answers yes, yes, …, yes, no, no, …, no), and we want the boundary between the yes part and the no part.

Write it with two indices and an invariant that never breaks:

everything at index ≤ left is "yes"; everything at index ≥ right is "no".

Start with left = −1 and right = n: imaginary cells outside the array, so the invariant holds before looking at anything, and the empty cases need no special code. Each step tests the middle and moves one end there. When right − left == 1 the boundary lies between them: left is the last "yes", right is the first "no".

int left = -1, right = n;
while (right - left > 1) {
    int middle = left + (right - left) / 2;
    if (yes(middle)) left = middle; else right = middle;
}

The loop runs about log₂ n times (17 for n = 100 000), and middle is always a real index between them.

2How it maps onto this problem

Step 1: the question

"Largest member of A not exceeding x" is the last index with A[i] ≤ x. The question "A[i] ≤ x?" is yes then no along the sorted array, so it is the template with yes(i) = A[i] <= x.

Step 2: reading the answer

  • left ≥ 0: the answer is A[left].
  • left = −1: even A[0] is bigger than x; print −1.

Step 3: the queries are real numbers

The statement says the queries are real numbers (for example 14.5). Read them as double: comparing an int with a double converts the int exactly, so A[i] ≤ x is still the right test. Reading them as int would stop at the decimal point and break the rest of the input.

Traps
  • The statement forbids library binary search (lower_bound, upper_bound, binary_search): write the loop.
  • while (left <= right) versions with mid ± 1 are easy to get off by one; the invariant version has no ±1 at all.
  • Linear scanning per query: 10¹⁰ steps.

3Solution

main.cpp⬇ .cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<int> sorted(n);
    // index = 0..n-1: the array is already strictly increasing
    for (int index = 0; index < n; index++) cin >> sorted[index];

    string output;
    // query = 0..m-1: each query is answered on its own
    for (int query = 0; query < m; query++) {
        double x;                               // the queries may be real numbers
        cin >> x;
        // Invariant: sorted[left] <= x is still possible, sorted[right] > x is known.
        // Treat left = -1 as "nothing <= x" and right = n as "past the end".
        int left = -1, right = n;
        // halve [left, right] until they are neighbours
        while (right - left > 1) {
            int middle = left + (right - left) / 2;
            if (sorted[middle] <= x) left = middle;   // middle is a candidate: move up
            else right = middle;                      // too big: answer is below middle
        }
        output += (left == -1 ? "-1" : to_string(sorted[left]));
        output += '\n';
    }
    cout << output;
}

1เทคนิค: binary search หารอยต่อ ด้วยเงื่อนไขคงที่

binary search ทุกข้อในคอร์สนี้คือแนวคิดเดียวกัน: คำถามใช่/ไม่ใช่ที่เป็นทางเดียว (monotone) บนช่วงที่เรียงแล้ว ("A[i] ≤ x ไหม?" ตอบ ใช่, ใช่, …, ใช่, ไม่, ไม่, …, ไม่) และเราต้องการ รอยต่อ ระหว่างส่วนที่ใช่กับส่วนที่ไม่ใช่

เขียนด้วยดัชนีสองตัวและเงื่อนไขคงที่ที่ไม่มีวันผิด:

ทุกดัชนี ≤ left ตอบ "ใช่" และทุกดัชนี ≥ right ตอบ "ไม่"

เริ่มที่ left = −1 และ right = n: ช่องสมมตินอกอาร์เรย์ เงื่อนไขจึงจริงตั้งแต่ก่อนดูข้อมูลใด ๆ และกรณีว่างไม่ต้องเขียนโค้ดพิเศษ แต่ละขั้นตรวจตรงกลางแล้วย้ายปลายข้างหนึ่งมาที่นั่น เมื่อ right − left == 1 รอยต่ออยู่ระหว่างทั้งสอง: left คือ "ใช่" ตัวสุดท้าย และ right คือ "ไม่" ตัวแรก

int left = -1, right = n;
while (right - left > 1) {
    int middle = left + (right - left) / 2;
    if (yes(middle)) left = middle; else right = middle;
}

ลูปทำงานราว log₂ n รอบ (17 รอบเมื่อ n = 100 000) และ middle เป็นดัชนีจริงระหว่างทั้งสองเสมอ

2นำมาใช้กับโจทย์นี้อย่างไร

ขั้นที่ 1: คำถาม

"สมาชิกที่มากที่สุดของ A ที่ไม่เกิน x" คือดัชนี สุดท้าย ที่ A[i] ≤ x คำถาม "A[i] ≤ x?" เป็น ใช่ แล้ว ไม่ ตามอาร์เรย์ที่เรียง จึงเป็นแม่แบบโดยใช้ yes(i) = A[i] <= x

ขั้นที่ 2: อ่านคำตอบ

  • left ≥ 0: คำตอบคือ A[left]
  • left = −1: แม้แต่ A[0] ก็มากกว่า x พิมพ์ −1

ขั้นที่ 3: คำถามเป็นจำนวนจริง

โจทย์บอกว่าคำถามเป็นจำนวน จริง (เช่น 14.5) จึงอ่านเป็น double: การเทียบ int กับ double แปลง int ได้แม่นยำ A[i] ≤ x จึงยังถูกต้อง ถ้าอ่านเป็น int จะหยุดที่จุดทศนิยมและทำให้ข้อมูลที่เหลืออ่านผิดหมด

กับดัก
  • โจทย์ห้ามใช้ binary search ของไลบรารี (lower_bound, upper_bound, binary_search): ต้องเขียนลูปเอง
  • แบบ while (left <= right) ที่มี mid ± 1 พลาดทีละหนึ่งได้ง่าย แบบเงื่อนไขคงที่ไม่มี ±1 เลย
  • ไล่ทีละตัวทุกคำถาม: 10¹⁰ ขั้น
